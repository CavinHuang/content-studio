# ContentDeck M2 实施计划：pi agent 集成 + 创作流（草稿区/确认落盘/ask_user）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 M1 的应用壳/内容库/编辑器之上内置 pi agent（进程内嵌入），交付创作流：编辑器内有 AI 面板——按技能（长文初稿/审稿改稿）产出、运行中可问询（ask_user）、产出只落草稿区 `.studio/drafts/<内容id>/`、用户确认后经既有原子写进正文；全程不依赖真实 API key（单测合成 fixture、e2e 本地 mock OpenAI 兼容端点）。

**Architecture:** pi 以 ESM 包形态被主进程 **动态 `import()`**（宿主 main bundle 是 CJS），绝不进 vite bundle（externalize）；每条内容一个绑定 pi 会话（cwd=内容文件夹，JSONL 持久化于库内 `.studio/pi-sessions/<内容id>/`）；领域工具（`noTools:'all'` 关闭 pi 内置 read/bash/edit/write，只挂 4 个自定义工具）是 agent 操作工作台的唯一能力；流式事件经 `session.subscribe` 归一化后由 `webContents.send('studio:agent:event')` 转发渲染进程；模型配置存 userData（pi 的 models.json/auth.json 也放 userData 的 `pi-agent/`，不与 `~/.pi/agent` 混用）。

**Tech Stack:** 在 M1 栈上加 `@earendil-works/pi-coding-agent@1.4.0` 与 `typebox@1.3.27`（均**精确版本锁定**，spec §5"版本锁定"；升级是显式决策）。无新框架。

**Spec:** `docs/superpowers/specs/2026-10-24-content-ops-workbench-design.md`（本计划实现其 §10 M2 行：pi 集成、领域工具、创作流；§5 pi agent 集成、§3 安全基线、§4.1 数据模型、§8 错误处理全程生效）

## 探针已验证事实（执行者必读，勿重新发明）

以下全部在写本计划时**实际跑通**（pi 1.4.0 安装于临时目录，系统 Node 24.1.0 + 本地 mock OpenAI SSE 端点）：

1. `await import('@earendil-works/pi-coding-agent')` 进程内加载成功；根入口**不**触发 pi-tui 原生模块（与探针结论一致）。
2. **`ModelRuntime.create({ agentDir })` 不会读 `<agentDir>/models.json`**——`model-runtime.js:81` 是 `options.modelsPath ?? join(getAgentDir(), "models.json")`，`getAgentDir()` 恒为全局 `~/.pi/agent`。必须**显式传 `modelsPath`/`authPath`**。
3. models.json 的 provider 支持 `apiKey` **字面量**（`{ providers: { x: { baseUrl, api: 'openai-completions', apiKey: 'k', models: [{id,...}] } } }`），模型即可用，无需 `setRuntimeApiKey`。
4. `noTools: 'all'` + `customTools: [领域工具]` + `tools: ['list_contents',...]` 组合实测：**发给模型的 tools 声明只有领域工具，pi 内置 read/bash/edit/write 零泄漏**（人机边界铁律的机械保证）。
5. `SessionManager.create(cwd, sessionDir)` / `continueRecent(cwd, sessionDir)` 第二参自定义会话目录：JSONL 实测落在指定目录；条目类型 `session/model_change/thinking_level_change/message`。
6. 流式事件实测齐全：`agent_start / turn_start / message_start / message_update(text_delta) / message_end / tool_execution_start / tool_execution_end / turn_end / agent_end / agent_settled`；`abort()` 可取消、`waitForIdle()` 可等待。
7. `loadSkillsFromDir({ dir, source })` 读 `<dir>/<name>/SKILL.md`（frontmatter `name/description`）；`DefaultResourceLoader({ skillsOverride: () => ({skills, diagnostics}) })` 注入；`session.prompt('/skill:longform-draft 参数')` 默认展开为含 SKILL.md 全文的 user message（实测进入模型请求）。技能 name **用 ASCII**（`/skill:<name>` 展开对非 ASCII 名未验证）。
8. `typebox` 是 pi 的直接依赖（v1.3.27），独立包名，`await import('typebox')` 可用；领域工具的参数 schema 用它（与 pi 的 `ToolDefinition<TParams extends TSchema>` 同源）。
9. 工具结果形状：`{ content: [{ type:'text', text }], isError?: boolean }`；`isError:true` 时模型看到错误结果但不抛异常。
10. **Windows 陷阱**：agent 会话存活期间调 `process.exit()` 会触发 libuv 断言（`UV_HANDLE_CLOSING`）——退出前必须 `session.dispose()`（本计划在 `will-quit` 处理），且 e2e/脚本不要用 `process.exit`。

## Global Constraints

- 既有 M1 能力**只复用不重构**：`content-library.ts` 的 `writeBody`（原子写）承担确认落盘；所有既有测试保持绿。
- pi 只经 `src/main/agent/pi-loader.ts` **动态 import**；任何文件不得静态 `import '@earendil-works/pi-coding-agent'`（`import type` 除外）；**严禁 import pi 的 TUI/modes 路径**（InteractiveMode 等，会触发 pi-tui 原生 prebuild，asar 内必炸——探针铁律）。
- `vite.main.config.ts` 的 `rollupOptions.external` 必须含 `'@earendil-works/pi-coding-agent'` 与 `'typebox'`（pi 运行时 `require.resolve("typebox")`、读包内相对文件，进 bundle 即运行时断链）。
- 人机边界铁律（spec §5）：AI 产出=假设——`write_draft` 只写 `.studio/drafts/<内容id>/`；进正文的唯一路径是用户在 UI 点「采纳入正文」→ 既有 `writeBody`；AI 永远不触发发布（M2 根本没有发布工具）。
- 会话模型（spec §5）：每内容一个绑定会话（`.studio/pi-sessions/<内容id>/`，`continueRecent` 续聊）；运营全局会话留 M4（键名预留见 Task 5 注）。
- 并发与取消（spec §5，前身项目教训）：全局并发上限 **1**（`AGENT_BUSY` 拒绝）；任何时刻可取消（`abort()` + 未决 ask_user 一并落 settles）；类字段先声明后使用，杜绝 TDZ 类低级错误。
- 模型配置走 pi provider 体系（spec §5）：OpenAI 兼容 baseUrl + apiKey + modelId，存 userData（`settings.json` 与 `pi-agent/models.json`），**绝不写进内容库目录**、不与用户可能安装的 pi CLI 共用 `~/.pi/agent`。
- 单测不联网：pi 相关单测只做进程内加载/纯逻辑/合成 fixture；完整模型链路只在 e2e 用本地 mock OpenAI 端点（127.0.0.1）。
- 安全基线不变（spec §3）：渲染进程无 fs/node，一切经 `window.studio.agent` 桥；IPC 通道按 `studio:agent:*` 域最小暴露。
- UI 文案全部中文；可达名（aria-label）以各任务测试为准（e2e 依赖）。
- 每个任务收尾跑 `npm run typecheck && npm test`，绿了才 commit；不推送远端。
- M2 明确不做：`save_variant`/`create_publish_task`（M3）、`query_schedule`/`query_metrics`/`search_sparks` 与运营全局会话（M4，依赖 SQLite 运营域）、一稿多态转化技能（M3）。

```ts
/**
 * pi 与 typebox 的唯一运行时入口。
 * - pi 仅 ESM（type:module）且需保持包结构完整：只能动态 import + vite external，严禁静态引入。
 * - 严禁 import pi 的 TUI/modes 路径（InteractiveMode 等）：会触发 pi-tui 原生 prebuild，
 *   .node 无法从 asar 内加载（探针 dlopen 追踪结论；根入口不加载原生模块）。
 * - typebox 是 pi 的直接依赖（同名包），领域工具的参数 schema 复用同一实现。
 */
export type PiModule = typeof import('@earendil-works/pi-coding-agent');
export type TypeBoxModule = typeof import('typebox');

let piPromise: Promise<PiModule> | null = null;
let typeboxPromise: Promise<TypeBoxModule> | null = null;

export function loadPi(): Promise<PiModule> {
  piPromise ??= import('@earendil-works/pi-coding-agent');
  return piPromise;
}

export function loadTypebox(): Promise<TypeBoxModule> {
  typeboxPromise ??= import('typebox');
  return typeboxPromise;
}
```

- [ ] **Step 3: 实现 `src/main/drafts.ts`**

```ts
import { mkdir, readdir, readFile, writeFile, rename, unlink } from 'node:fs/promises';
import { randomBytes } from 'node:crypto';
import path from 'node:path';
import matter from 'gray-matter';
import type { DraftSummary } from '../shared/types';
import { writeBody } from './content-library';

export function draftsDir(root: string, contentId: string): string {
  return path.join(root, '.studio', 'drafts', contentId);
}

function stamp(d = new Date()): string {
  const p = (n: number) => String(n).padStart(2, '0');
  return `${d.getFullYear()}${p(d.getMonth() + 1)}${p(d.getDate())}-${p(d.getHours())}${p(d.getMinutes())}${p(d.getSeconds())}`;
}

export async function saveDraft(
  root: string, contentId: string, input: { markdown: string; note?: string },
): Promise<DraftSummary> {
  const dir = draftsDir(root, contentId);
  await mkdir(dir, { recursive: true });
  const created = new Date().toISOString();
  const name = `draft-${stamp()}-${randomBytes(2).toString('hex')}.md`;
  const file = path.join(dir, name);
  // 与 content-library 同策略：唯一临时名 + rename（并发写互不覆盖）
  const tmp = `${file}.${randomBytes(6).toString('hex')}.tmp`;
  const front = matter.stringify('', { created, note: input.note ?? '' }).slice(0, -1); // `---\n<yaml>\n---\n`
  await writeFile(tmp, front + input.markdown, 'utf8');
  await rename(tmp, file);
  return { name, created, note: input.note ?? '', bytes: Buffer.byteLength(input.markdown, 'utf8') };
}

export async function listDrafts(root: string, contentId: string): Promise<DraftSummary[]> {
  let entries;
  try { entries = await readdir(draftsDir(root, contentId), { withFileTypes: true }); }
  catch { return []; } // 目录不存在=无草稿
  const out: DraftSummary[] = [];
  for (const e of entries) {
    if (!e.isFile() || !e.name.endsWith('.md')) continue;
    try {
      const raw = await readFile(path.join(draftsDir(root, contentId), e.name), 'utf8');
      const { data, content } = matter(raw);
      out.push({
        name: e.name,
        created: String(data.created ?? ''),
        note: String(data.note ?? ''),
        bytes: Buffer.byteLength(content, 'utf8'),
      });
    } catch { /* 单文件损坏跳过，不阻塞列表 */ }
  }
  out.sort((a, b) => b.created.localeCompare(a.created));
  return out;
}

function assertDraftName(name: string): void {
  if (path.basename(name) !== name || name.includes('..')) {
    const err = new Error(`非法草稿名: ${name}`) as Error & { code: string };
    err.code = 'DRAFT_BAD_NAME';
    throw err;
  }
}

export async function readDraft(root: string, contentId: string, name: string): Promise<string> {
  assertDraftName(name);
  const raw = await readFile(path.join(draftsDir(root, contentId), name), 'utf8');
  return matter(raw).content;
}

/** 人确认后的落盘：草稿正文 → 既有原子 writeBody（frontmatter 保留）→ 消费草稿。 */
export async function applyDraft(root: string, contentId: string, name: string): Promise<{ savedAt: string }> {
  const body = await readDraft(root, contentId, name);
  const r = await writeBody(root, contentId, body);
  await unlink(path.join(draftsDir(root, contentId), name)).catch(() => {});
  return r;
}

export async function discardDraft(root: string, contentId: string, name: string): Promise<void> {
  assertDraftName(name);
  await unlink(path.join(draftsDir(root, contentId), name));
}
```

```ts
import { listContents, readContent } from '../content-library';
import { saveDraft } from '../drafts';
import type { PiModule, TypeBoxModule } from './pi-loader';

export type AskUserFn = (question: string, options: string[] | undefined) => Promise<string>;

export interface DomainToolDeps {
  root: string;
  askUser: AskUserFn;
}

const TOOL_NAMES = ['list_contents', 'read_content', 'write_draft', 'ask_user'] as const;
export type DomainToolName = (typeof TOOL_NAMES)[number];
export function domainToolNames(): readonly DomainToolName[] { return TOOL_NAMES; }

function text(t: string) { return { content: [{ type: 'text' as const, text: t }] }; }
function textErr(t: string) { return { content: [{ type: 'text' as const, text: t }], isError: true }; }

export async function buildDomainTools(pi: PiModule, T: TypeBoxModule, deps: DomainToolDeps) {
  const listContentsTool = pi.defineTool({
    name: 'list_contents',
    label: '列出内容',
    description: '列出内容库中的所有内容（id、标题、阶段、标签、创建日期）。可用 stage 过滤（idea/draft/review/variants/publishing/published/retro）。',
    parameters: T.Type.Object({ stage: T.Type.Optional(T.Type.String()) }),
    annotations: { readOnlyHint: true },
    async execute(_id, params) {
      try {
        const scan = await listContents(deps.root);
        const items = params.stage ? scan.items.filter((m) => m.stage === params.stage) : scan.items;
        return text(JSON.stringify(
          items.map(({ id, title, stage, tags, created }) => ({ id, title, stage, tags, created })), null, 2));
      } catch (err) { return textErr(`list_contents 失败：${String(err)}`); }
    },
  });
  const readContentTool = pi.defineTool({
    name: 'read_content',
    label: '读取内容',
    description: '按 id 读取一篇内容的元数据与 Markdown 全文。',
    parameters: T.Type.Object({ id: T.Type.String() }),
    annotations: { readOnlyHint: true },
    async execute(_id, params) {
      try {
        const c = await readContent(deps.root, params.id);
        return text(`# ${c.title}（id=${c.id}，stage=${c.stage}，tags=${c.tags.join(',')}）\n\n${c.body}`);
      } catch (err) { return textErr(`read_content 失败：${String(err)}`); }
    },
  });
  const writeDraftTool = pi.defineTool({
    name: 'write_draft',
    label: '写入草稿区',
    description: '把产出的 Markdown 全文写入该内容的草稿区（.studio/drafts/<内容id>/）。这是 AI 产出的唯一落点，不会修改正文；用户确认后才进正文。',
    parameters: T.Type.Object({
      id: T.Type.String(),
      markdown: T.Type.String(),
      note: T.Type.Optional(T.Type.String({ description: '草稿备注，如「长文初稿」「审稿改稿」' })),
    }),
    annotations: { destructiveHint: false },
    async execute(_id, params) {
      try {
        await readContent(deps.root, params.id); // 校验内容存在（防孤儿草稿）
        const d = await saveDraft(deps.root, params.id, { markdown: params.markdown, note: params.note });
        return text(`草稿已保存：${d.name}（等待人工确认采纳，不会自动进正文）`);
      } catch (err) { return textErr(`write_draft 失败：${String(err)}`); }
    },
  });
  const askUserTool = pi.defineTool({
    name: 'ask_user',
    label: '问询用户',
    description: '向用户提一个问题（可给选项列表），等待回答。创作方向、取舍等决策拿不准时必须先问。',
    parameters: T.Type.Object({
      question: T.Type.String(),
      options: T.Type.Optional(T.Type.Array(T.Type.String())),
    }),
    annotations: { readOnlyHint: true },
    execute(_id, params, signal) {
      return new Promise((resolve) => {
        let settled = false;
        const done = (t: string) => { if (!settled) { settled = true; resolve(text(t)); } };
        const onAbort = () => done('（任务已取消，未获得用户回答）');
        signal?.addEventListener('abort', onAbort, { once: true });
        void deps.askUser(params.question, params.options).then((answer) => {
          signal?.removeEventListener('abort', onAbort);
          done(`用户回答：${answer}`);
        });
      });
    },
  });
  return [listContentsTool, readContentTool, writeDraftTool, askUserTool];
}
```

```ts
import { mkdir, writeFile } from 'node:fs/promises';
import path from 'node:path';
import type { ModelConfig } from '../../shared/types';
import { loadSettings, saveSettings } from '../settings';

const PROVIDER_ID = 'contentdeck' as const;

function invalid(message: string): Error & { code: string } {
  const err = new Error(message) as Error & { code: string };
  err.code = 'MODEL_CONFIG_INVALID';
  return err;
}

export function validateModelConfig(input: { name?: string; baseUrl: string; apiKey: string; modelId: string }): ModelConfig {
  const baseUrl = String(input.baseUrl ?? '').trim();
  const apiKey = String(input.apiKey ?? '');
  const modelId = String(input.modelId ?? '').trim();
  if (!/^https?:\/\/.+/i.test(baseUrl)) throw invalid('API 地址必须以 http:// 或 https:// 开头');
  if (!apiKey) throw invalid('API Key 不能为空（本地无鉴权端点可填任意占位值）');
  if (!modelId) throw invalid('模型 ID 不能为空');
  const name = input.name?.trim();
  return { providerId: PROVIDER_ID, ...(name ? { name } : {}), baseUrl, apiKey, modelId };
}

export function getModelConfig(): ModelConfig | null {
  return loadSettings().model ?? null;
}

export function setModelConfig(input: { name?: string; baseUrl: string; apiKey: string; modelId: string }): ModelConfig {
  const c = validateModelConfig(input);
  saveSettings({ ...loadSettings(), model: c });
  return c;
}

/** pi 的 agentDir：用户数据目录下专属子目录。绝不与用户可能安装的 pi CLI 共用 ~/.pi/agent（探针风险：会话迁移与版本串扰）。 */
export function piAgentDir(): string {
  return path.join(process.env.CONTENTDECK_USER_DATA ?? '', 'pi-agent');
}

/** 生成 pi ModelRuntime 可用的 models.json（探针实证：provider apiKey 支持字面量，模型即可用）。 */
export async function writePiModelsJson(c: ModelConfig): Promise<string> {
  const dir = piAgentDir();
  await mkdir(dir, { recursive: true });
  const file = path.join(dir, 'models.json');
  const doc = {
    providers: {
      [c.providerId]: {
        name: c.name ?? '自定义模型',
        baseUrl: c.baseUrl,
        api: 'openai-completions',
        apiKey: c.apiKey, // 本地优先：随 userData 存放，不进内容库/git
        models: [{ id: c.modelId, name: c.modelId, contextWindow: 128000, maxTokens: 16384 }],
      },
    },
  };
  await writeFile(file, JSON.stringify(doc, null, 2), 'utf8');
  return file;
}
```

```ts
import { randomBytes } from 'node:crypto';
import type { AgentEventOut, AgentSendResult, AgentErrorCode } from '../../shared/types';
import type { AskUserFn } from './domain-tools';

export type PiEventLike = { type: string } & Record<string, unknown>;

export interface SessionLike {
  subscribe(listener: (ev: PiEventLike) => void): () => void;
  prompt(text: string): Promise<void>;
  abort(): Promise<void>;
  waitForIdle(): Promise<void>;
  dispose(): void;
}
export type CreateSessionFn = (contentId: string, askUser: AskUserFn) => Promise<SessionLike>;

export interface AgentServiceDeps {
  createSession: CreateSessionFn;
  emit: (ev: AgentEventOut) => void;
  hasModelConfig: () => boolean;
}

function msg(err: unknown): string { return err instanceof Error ? err.message : String(err); }
function codeOf(err: unknown): AgentErrorCode {
  const c = (err as { code?: unknown })?.code;
  return (typeof c === 'string' && c ? c : 'AGENT_ERROR') as AgentErrorCode;
}
function safeJson(v: unknown): string { try { return JSON.stringify(v) ?? ''; } catch { return String(v); } }
function firstText(v: unknown): string {
  const c = (v as { content?: Array<{ type?: string; text?: string }> } | undefined)?.content;
  const t = Array.isArray(c) ? c.find((x) => x?.type === 'text')?.text : undefined;
  return t ? t.slice(0, 120) : '';
}

export class AgentService {
  /** 全局并发上限=1（spec §5 前身项目实证教训）。 */
  static readonly MAX_ACTIVE_RUNS = 1;
  private readonly sessions = new Map<string, SessionLike>();
  private activeRun: { contentId: string; runId: string } | null = null;
  private readonly asks = new Map<string, (answer: string) => void>();

  constructor(private readonly deps: AgentServiceDeps) {}

  async send(contentId: string, text: string): Promise<AgentSendResult> {
    if (!text.trim()) return { ok: false, code: 'EMPTY_INPUT', message: '指令为空' };
    if (this.activeRun) return { ok: false, code: 'AGENT_BUSY', message: '已有任务在运行，请等待完成或先取消' };
    if (!this.deps.hasModelConfig()) return { ok: false, code: 'NO_MODEL_CONFIG', message: '尚未配置模型，请先在「AI 设置」中配置' };
    // 忙检查与占用必须原子：在 await ensureSession（pi 冷加载数秒）之前同步置位，
    // 否则窗口内二次 send 绕过并发上限、对同一 contentId 双建会话（spec §5 铁律）。
    const runId = `r_${Date.now().toString(36)}_${randomBytes(3).toString('hex')}`;
    this.activeRun = { contentId, runId };
    let session: SessionLike;
    try { session = await this.ensureSession(contentId); }
    catch (err) {
      this.activeRun = null; // 建会话失败：释放占位，服务不永久 busy
      return { ok: false, code: codeOf(err), message: msg(err) };
    }
    this.deps.emit({ kind: 'run_start', contentId, runId });
    void this.runPrompt(session, contentId, runId, text);
    return { ok: true, runId };
  }

  private async runPrompt(session: SessionLike, contentId: string, runId: string, text: string): Promise<void> {
    try {
      await session.prompt(text);
      await session.waitForIdle();
      this.deps.emit({ kind: 'run_end', contentId, runId, ok: true });
    } catch (err) {
      this.deps.emit({ kind: 'run_end', contentId, runId, ok: false, error: msg(err) });
    } finally {
      this.activeRun = null;
      this.settleAsks('（任务已取消）'); // 未决问询不悬空（TDZ/悬垂教训：finally 里统一收口）
    }
  }

  async cancel(contentId: string): Promise<void> {
    this.settleAsks('（任务已取消）');
    const session = this.sessions.get(contentId);
    if (session) await session.abort();
  }

  answer(contentId: string, questionId: string, answer: string): void {
    void contentId; // questionId 全局唯一即可；contentId 留作日志/校验扩展
    const resolve = this.asks.get(questionId);
    if (resolve) { this.asks.delete(questionId); resolve(answer); }
  }

  disposeAll(): void {
    for (const s of this.sessions.values()) s.dispose();
    this.sessions.clear();
    this.settleAsks('（应用退出）');
  }

  private async ensureSession(contentId: string): Promise<SessionLike> {
    const cached = this.sessions.get(contentId);
    if (cached) return cached;
    const askUser: AskUserFn = (question, options) => new Promise<string>((resolve) => {
      const questionId = `q_${randomBytes(4).toString('hex')}`;
      this.asks.set(questionId, resolve);
      this.deps.emit({
        kind: 'ask', contentId,
        runId: this.activeRun?.runId ?? '',
        questionId, question, options,
      });
    });
    const session = await this.deps.createSession(contentId, askUser);
    this.wireEvents(session, contentId);
    this.sessions.set(contentId, session);
    return session;
  }

  private wireEvents(session: SessionLike, contentId: string): void {
    session.subscribe((ev) => {
      const runId = this.activeRun?.contentId === contentId ? this.activeRun.runId : null;
      if (!runId) return;
      if (ev.type === 'message_update') {
        const ame = ev.assistantMessageEvent as { type?: string; delta?: string } | undefined;
        if (ame?.type === 'text_delta' && ame.delta) this.deps.emit({ kind: 'delta', contentId, runId, text: ame.delta });
        return;
      }
      if (ev.type === 'tool_execution_start') {
        this.deps.emit({ kind: 'tool_start', contentId, runId, tool: String(ev.toolName), args: safeJson(ev.args) });
        return;
      }
      if (ev.type === 'tool_execution_end') {
        const tool = String(ev.toolName);
        this.deps.emit({ kind: 'tool_end', contentId, runId, tool, isError: Boolean(ev.isError), summary: firstText(ev.result) });
        if (tool === 'write_draft') this.deps.emit({ kind: 'drafts_changed', contentId });
      }
    });
  }

  private settleAsks(fallback: string): void {
    for (const resolve of this.asks.values()) resolve(fallback);
    this.asks.clear();
  }
}
```

```ts
import { mkdir } from 'node:fs/promises';
import path from 'node:path';
import { listContents } from '../content-library';
import type { SessionLike, CreateSessionFn } from './agent-service';
import { buildDomainTools, domainToolNames, type AskUserFn } from './domain-tools';
import { loadPi, loadTypebox } from './pi-loader';
import { getModelConfig, piAgentDir, writePiModelsJson } from './model-config';

export interface RealSessionFactoryDeps {
  root: () => string | null;
  skillsDir: () => string;
}

function coded(message: string, code: string): Error & { code: string } {
  const err = new Error(message) as Error & { code: string };
  err.code = code;
  return err;
}

/**
 * 真实 pi 会话：每内容一个绑定会话（cwd=内容文件夹），JSONL 持久化于
 * .studio/pi-sessions/<内容id>/（continueRecent 续聊）。noTools:'all' 关闭 pi
 * 内置 read/bash/edit/write——agent 只有领域工具（探针实测零泄漏，铁律机械化）。
 */
export function createRealSessionFactory(deps: RealSessionFactoryDeps): CreateSessionFn {
  return async (contentId: string, askUser: AskUserFn): Promise<SessionLike> => {
    const root = deps.root();
    if (!root) throw coded('尚未选择内容库', 'NO_LIBRARY');
    const cfg = getModelConfig();
    if (!cfg) throw coded('尚未配置模型', 'NO_MODEL_CONFIG');
    const scan = await listContents(root);
    const meta = scan.items.find((m) => m.id === contentId && m.id !== '');
    if (!meta) throw coded(`内容不存在: ${contentId}`, 'CONTENT_NOT_FOUND');

    const contentDir = path.join(root, meta.folder);
    const sessionDir = path.join(root, '.studio', 'pi-sessions', contentId);
    await mkdir(sessionDir, { recursive: true });

    const pi = await loadPi();
    const T = await loadTypebox();
    const agentDir = piAgentDir();
    await mkdir(agentDir, { recursive: true });
    await writePiModelsJson(cfg);
    // 探针实证：ModelRuntime.create 不读 <agentDir>/models.json，必须显式传路径
    const modelRuntime = await pi.ModelRuntime.create({
      modelsPath: path.join(agentDir, 'models.json'),
      authPath: path.join(agentDir, 'auth.json'),
    });
    const model = modelRuntime.getModel(cfg.providerId, cfg.modelId);
    if (!model) throw coded(`模型不可用: ${cfg.providerId}/${cfg.modelId}`, 'MODEL_NOT_FOUND');

    const skills = pi.loadSkillsFromDir({ dir: deps.skillsDir(), source: 'contentdeck' });
    const loader = new pi.DefaultResourceLoader({
      cwd: contentDir,          // 上下文绑定该内容文件夹（spec §5）
      agentDir,                 // 独立 agentDir：不与用户 pi CLI 的 ~/.pi/agent 混用
      skillsOverride: () => skills, // 技能只来自随应用分发的目录
    });
    await loader.reload();

    const customTools = await buildDomainTools(pi, T, { root, askUser });
    const { session } = await pi.createAgentSession({
      cwd: contentDir,
      agentDir,
      model,
      modelRuntime,
      resourceLoader: loader,
      noTools: 'all',                          // 关闭全部内置工具
      customTools,
      tools: [...domainToolNames()],           // 只启用领域工具
      sessionManager: pi.SessionManager.continueRecent(contentDir, sessionDir),
    });
    return {
      subscribe: (l) => session.subscribe(l as never),
      prompt: (text) => session.prompt(text),
      abort: () => session.abort(),
      waitForIdle: () => session.waitForIdle(),
      dispose: () => session.dispose(),
    };
  };
}
```

```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import { agentBridge } from '../lib/agent-bridge';
import type { AgentEventOut, DraftSummary } from '../../../shared/types';
import { ModelSettingsModal } from './ModelSettingsModal';

const SKILLS = [
  { label: '长文初稿', command: '/skill:longform-draft' },
  { label: '审稿改稿', command: '/skill:review-revise' },
] as const;

type Line = { role: 'user' | 'assistant' | 'tool' | 'alert'; text: string };

export function AgentPanel({ contentId, onApplied }: { contentId: string; onApplied: () => void }) {
  const [lines, setLines] = useState<Line[]>([]);
  const [input, setInput] = useState('');
  const [running, setRunning] = useState(false);
  const [ask, setAsk] = useState<{ questionId: string; question: string; options?: string[] } | null>(null);
  const [freeAnswer, setFreeAnswer] = useState('');
  const [drafts, setDrafts] = useState<DraftSummary[]>([]);
  const [showSettings, setShowSettings] = useState(false);
  const runningRef = useRef(false);

  const refreshDrafts = useCallback(async () => {
    setDrafts(await agentBridge.listDrafts(contentId));
  }, [contentId]);
  useEffect(() => { void refreshDrafts(); }, [refreshDrafts]);

  useEffect(() => {
    const off = agentBridge.onEvent((ev: AgentEventOut) => {
      if (ev.contentId !== contentId) return;
      switch (ev.kind) {
        case 'run_start':
          runningRef.current = true; setRunning(true); break;
        case 'delta':
          setLines((ls) => {
            const last = ls[ls.length - 1];
            if (last && last.role === 'assistant') return [...ls.slice(0, -1), { ...last, text: last.text + ev.text }];
            return [...ls, { role: 'assistant', text: ev.text }];
          });
          break;
        case 'tool_start':
          setLines((ls) => [...ls, { role: 'tool', text: `调用工具 ${ev.tool}` }]);
          break;
        case 'tool_end':
          if (ev.tool === 'write_draft') void refreshDrafts();
          break;
        case 'ask':
          setAsk({ questionId: ev.questionId, question: ev.question, options: ev.options });
          break;
        case 'run_end':
          runningRef.current = false; setRunning(false);
          if (!ev.ok) setLines((ls) => [...ls, { role: 'alert', text: `任务失败：${ev.error ?? '未知错误'}` }]);
          void refreshDrafts();
          break;
        case 'drafts_changed':
          void refreshDrafts();
          break;
      }
    });
    return off;
  }, [contentId, refreshDrafts]);

  const send = async (text: string) => {
    const t = text.trim();
    if (!t || runningRef.current) return;
    setLines((ls) => [...ls, { role: 'user', text: t }]);
    setInput('');
    const r = await agentBridge.send(contentId, t);
    if (!r.ok) setLines((ls) => [...ls, { role: 'alert', text: r.message }]);
  };

  const answer = async (a: string) => {
    if (!ask || !a.trim()) return;
    await agentBridge.answer(contentId, ask.questionId, a.trim());
    setLines((ls) => [...ls, { role: 'user', text: `（回答）${a.trim()}` }]);
    setAsk(null); setFreeAnswer('');
  };

  const apply = async (name: string) => {
    const r = await agentBridge.applyDraft(contentId, name);
    if (r.ok) { onApplied(); void refreshDrafts(); }
    else setLines((ls) => [...ls, { role: 'alert', text: `采纳失败：${r.message}` }]);
  };
```

```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import { EditorState } from '@codemirror/state';
import { EditorView, keymap } from '@codemirror/view';
import { markdown } from '@codemirror/lang-markdown';
import { defaultKeymap } from '@codemirror/commands';
import { bridge } from '../lib/bridge';
import { AgentPanel } from '../components/AgentPanel';
import type { Content } from '../../shared/types';

export function Editor({ id, onBack }: { id: string; onBack: () => void }) {
  const [content, setContent] = useState<Content | null>(null);
  const [saveState, setSaveState] = useState<'idle' | 'dirty' | 'saving' | 'saved' | 'error'>('idle');
  const [saveError, setSaveError] = useState<string | null>(null);
  const bodyRef = useRef('');
  const timer = useRef<ReturnType<typeof setTimeout> | null>(null);
  const viewRef = useRef<EditorView | null>(null);
  const hostRef = useRef<HTMLDivElement>(null);
  const applyingRef = useRef(false); // 外部应用正文（采纳入正文）时不触发自动保存回路

  useEffect(() => { void bridge.readContent(id).then((c) => {
    setContent(c); bodyRef.current = c.body;
  }); }, [id]);

  useEffect(() => () => { if (timer.current) clearTimeout(timer.current); }, []);

  const doSave = useCallback(async () => {
    setSaveState('saving');
    setSaveError(null);
    try {
      await bridge.saveBody(id, bodyRef.current);
      setSaveState('saved');
    } catch (err) {
      setSaveState('error');
      setSaveError(err instanceof Error ? err.message : String(err));
    }
  }, [id]);

  const onInput = useCallback((body: string) => {
    bodyRef.current = body;
    setSaveState('dirty');
    if (timer.current) clearTimeout(timer.current);
    timer.current = setTimeout(() => { void doSave(); }, 800);
  }, [doSave]);

  /** 草稿采纳入正文后：重读磁盘并把新正文灌回编辑器（不触发自动保存）。 */
  const applyExternalBody = useCallback(async () => {
    const c = await bridge.readContent(id);
    bodyRef.current = c.body;
    const v = viewRef.current;
    if (v) {
      applyingRef.current = true;
      v.dispatch({ changes: { from: 0, to: v.state.doc.length, insert: c.body } });
      applyingRef.current = false;
    }
    setSaveState('saved');
  }, [id]);

  useEffect(() => {
    if (!content || !hostRef.current || viewRef.current) return;
    const view = new EditorView({
      state: EditorState.create({
        doc: bodyRef.current,
        extensions: [
          markdown(), keymap.of(defaultKeymap),
          EditorView.contentAttributes.of({ 'aria-label': '正文编辑区' }),
          EditorView.updateListener.of((u) => {
            if (u.docChanged && !applyingRef.current) onInput(u.state.doc.toString());
          }),
        ],
      }),
      parent: hostRef.current,
    });
    viewRef.current = view;
    return () => { view.destroy(); viewRef.current = null; };
  }, [content?.id, onInput]);

  if (!content) return <div className="editor">载入中…</div>;
  const label = { idle: '', dirty: '未保存', saving: '保存中…', saved: '已保存', error: '保存失败' }[saveState];
  return (
    <div className="editor">
      <header className="editor-header">
        <button onClick={() => { if (timer.current) clearTimeout(timer.current); if (saveState === 'dirty' || saveState === 'error') void doSave(); onBack(); }}>← 返回看板</button>
        <input aria-label="内容标题" defaultValue={content.title} onBlur={async (e) => {
          const t = e.target.value.trim();
          if (t && t !== content.title) { await bridge.updateMeta(id, { title: t }); setContent({ ...content, title: t }); }
        }} />
        <span className="save-state" role="status" title={saveError ?? undefined}>{label}</span>
        {saveState === 'error' && <button className="save-retry" onClick={() => { void doSave(); }}>重试保存</button>}
      </header>
      <div className="editor-main">
        <div className="editor-body">
          <div ref={hostRef} className="cm-host" />
          <textarea className="a11y-fallback" aria-label="正文编辑区（回退）" aria-hidden="true" value={bodyRef.current}
            onChange={(e) => onInput(e.target.value)} tabIndex={-1} />
        </div>
        <aside className="agent-side">
          <AgentPanel contentId={id} onApplied={() => { void applyExternalBody(); }} />
        </aside>
      </div>
    </div>
  );
}
```

```ts
import http from 'node:http';

export type MockAction =
  | { type: 'text'; text: string }
  | { type: 'tool'; name: string; args: unknown };
export type MockScript = (req: { messages: Array<Record<string, unknown>>; tools?: unknown }) => MockAction[];

/** 本地 OpenAI 兼容 mock 端点（127.0.0.1，e2e 专用；不依赖真实 API key——既定模式）。 */
export class MockOpenai {
  readonly requests: { messages: Array<Record<string, unknown>>; tools?: unknown[] }[] = [];
  private readonly server: http.Server;
  private port = 0;
  constructor(private readonly script: MockScript) {
    this.server = http.createServer((req, res) => {
      let body = '';
      req.on('data', (c: string) => (body += c));
      req.on('end', () => {
        const parsed = JSON.parse(body) as { messages: Array<Record<string, unknown>>; tools?: unknown[] };
        this.requests.push({ messages: parsed.messages, tools: parsed.tools });
        const actions = this.script({ messages: parsed.messages, tools: parsed.tools });
        res.writeHead(200, { 'content-type': 'text/event-stream' });
        const sse = (obj: unknown) => res.write(`data: ${JSON.stringify(obj)}\n\n`);
        for (const a of actions) {
          if (a.type === 'text') {
            const half = Math.ceil(a.text.length / 2);
            for (const piece of [a.text.slice(0, half), a.text.slice(half)]) {
              if (piece) sse({ id: 'cmpl', object: 'chat.completion.chunk', choices: [{ index: 0, delta: { content: piece } }] });
            }
          } else {
            sse({ id: 'cmpl', object: 'chat.completion.chunk', choices: [{ index: 0, delta: { tool_calls: [{ index: 0, id: 'call_1', type: 'function', function: { name: a.name, arguments: JSON.stringify(a.args) } }] } }] });
          }
        }
        sse({ id: 'cmpl', object: 'chat.completion.chunk', choices: [{ index: 0, delta: {}, finish_reason: actions.some((a) => a.type === 'tool') ? 'tool_calls' : 'stop' }] });
        res.write('data: [DONE]\n\n');
        res.end();
      });
    });
  }
  get url(): string { return `http://127.0.0.1:${this.port}/v1`; }
  lastRequest() { return this.requests[this.requests.length - 1]; }
  async start(): Promise<string> {
    await new Promise<void>((r) => this.server.listen(0, '127.0.0.1', () => r()));
    this.port = (this.server.address() as { port: number }).port;
    return this.url;
  }
  async close(): Promise<void> { await new Promise<void>((r) => this.server.close(() => r())); }
}
```
