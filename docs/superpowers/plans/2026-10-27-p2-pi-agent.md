# P2 AI 创作链 · pi agent 全面接入 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 所有 agent 能力（对话、建议、母稿生成、平台改写）由主进程内嵌的 pi agent 1.4.0 真实驱动；未配置模型或 dev:web 降级时保留现有本地演示路径。

**Architecture:** 从 git 历史 M2（d60c4ab）移植验证过的 pi 集成骨架（动态 import + externalize、models.json 显式传、noTools:'all' 只挂领域工具、并发 1、可取消、ask_user），适配当前状态模型：上下文由渲染端注入 prompt（不再有文件库读取工具）；AI 产出经"运行产出缓冲"随事件回渲染端，转为 Suggestion/candidate（人机边界：AI 只落候选，采用需用户确认）；长任务（平台改写/母稿生成）走 P1 任务系统的主进程执行器，聊天走轻量 ai:* 流式通道。

**Tech Stack:** @earendil-works/pi-coding-agent 1.4.0（ESM，精确锁）、typebox 1.3.27、safeStorage、SQLite（ai_config 表）、IPC 事件流。

**Spec:** `docs/superpowers/specs/2026-10-27-full-implementation-design.md`（P2 节）

## Global Constraints

- pi 只能动态 import + electron-vite main rollupOptions.external（`['electron', '@earendil-works/pi-coding-agent', 'typebox']`）；严禁静态引入、严禁 import pi 的 TUI/modes 路径（asar 内 .node 必炸，探针实证）。
- models.json 必须显式传 `modelsPath`（ModelRuntime.create 不读 agentDir 下的 models.json）；agentDir = `<userData>/pi-agent`，绝不与用户 pi CLI 的 ~/.pi 混用。
- apiKey 全程不出主进程：safeStorage 加密存 SQLite；渲染端只见 `hasKey/apiKeyTail` 脱敏视图；保存占位 `KEEP_API_KEY` 沿用旧 key。
- 并发上限 1：忙检查与占用必须在 await（pi 冷加载数秒）之前同步置位（M2 评审教训）。
- AI 产出只落候选/建议（pending），采用需用户显式确认；不静默改正文（UX-SPEC §5 铁律）。
- 演示保留策略：未配置模型或 local（dev:web）模式 → 走现有本地演示路径（canned 回复/模板改写/抽取式母稿），e2e 现有断言稳定；配置后真实激活。全量摘演示推迟到 P5 收官统一处理。
- 新增用户可见文案全角标点、不泄漏路径、`(Mock)` 后缀仅限服务名实体（design:check N 系列门禁）。
- 每任务 `pnpm typecheck` + 相关测试绿后 conventional commit。
