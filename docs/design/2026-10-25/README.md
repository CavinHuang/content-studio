## 本轮设计结论

采用温暖杂志风：米白文稿、浅沙色分区、墨绿主操作、陶土色点缀。桌面始终使用「左侧内容库 / 中间当前产物 / 右侧 Agent 对话」。

内容主流程：热点选题或直接新建 → 收集与引用素材 → 确认创作方案 → 母稿或视频作品 → 平台版本 → 选择本次发布平台 → 预览、复制或导出 → 手动记录发布结果。

v1.1 新增「热点」全局入口：浏览话题与来源 → 选择并修改创作角度 → 新建内容并带入所选来源 → 确认创作方案。支持收藏与从同一热点发起多篇内容；热点数据接入与实时榜单尚未实现，效果图使用明确标注的示例话题。

v1.2 扩充多信息源设计：平台热榜、新闻资讯、RSS 与自定义来源独立管理；更新热点发现页，并新增来源管理页。当前总览共 20 张效果图，热点分类有 3 张。来源按实际接入能力启用，示例不代表已接入具体平台。

视频分为两条独立制作流程：

1. 素材分镜：脚本与素材 → 镜头编排 → 配音字幕 → 成片预览 → 视频或素材包。
2. Agent 代码创作：创作说明与参考 → 视觉方案 → 候选动画预览 → 对话迭代与版本采用 → 视频输出。

同一内容可以创建多部视频，两种方式分别保存作品；内容库、素材库和发布流程共用。

## 如何阅读效果图

此前已确认的界面构成主方向；视频入口、导出恢复、版本恢复、手机辅助为前序补齐。热点分类包含发现页、热点发起创作和来源管理，本轮将发现页升级为多源版本。各图状态在清单和总览中标明，完整交互见 UX-SPEC.md 第 20 节。

较早效果图中的顶层「分镜」入口，现统一升级为「视频」；两种视频的独立作品树以最新两套制作界面和交互规范为准，无需照搬早期图片中的旧导航。

效果图为图像设计稿，文案、字数、时长及计数属于示例，不代表平台限制或真实运行结果。正式页面状态、动作范围和数据规则以 UX-SPEC.md 为准。历史视频预览图仅用来说明素材路线中的预览，不作为两种模式共用编辑器。

## 交付边界

本设计完成个人创作者工作台的首轮 UI/UX，包括桌面核心界面、两条视频路线、常见任务状态与手机辅助流程。Remotion、HyperFrames、模型服务和桌面运行时属于后续技术验证项；本轮没有连接发布平台、执行视频渲染或改动原应用实现。

配色、尺寸和交互的实现基准见规范。图片中的字体和布局细节需要开发时按该规范落地。
