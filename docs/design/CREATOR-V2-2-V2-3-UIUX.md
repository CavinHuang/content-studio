# Creator V2.2 × V2.3 页面设计交付

设计基线：2026-10-19。范围为**新版 Creator 工作区**，不以旧版 StudioApp 的页面形态为重构基础。

## 本分支交付了什么

- 可运行的 Next.js 设计验收页：**/design/creator-v2**
- 11 个页面的交互式视觉方案：工作台、热点雷达、选题发现、作品库、创作空间、视觉工作台、发布中心、日历、效果复盘、素材库、偏好与连接。
- 配图专项的主路径：**编辑器内规划位置 → 独立视觉工作台选候选 → 明确采用 → 返回正文确认**。
- 桌面固定侧栏与移动底部导航；小屏将编辑器/视觉工作台改为单栏，隐藏非核心信息。
- 全部演示数据为硬编码、交互状态为 React 内存状态；**没有访问现有个人数据、触发付费模型、修改数据库、真正发布内容**。

本交付是**页面设计与原型集成**，不是 Creator 正式功能替换，不应被解释为已经上线生产新界面。无需迁移数据，也未改动已有 API 或安全检查。

## 完整导航和页面职责

| 页面 | 用户问题 | 主要动作 | 注意事项 |
|---|---|---|---|
| 工作台 | 今天继续做什么？ | 继续作品、创建文章 | 不用 KPI 塞满首屏 |
| 热点雷达 | 出现哪些值得观察的新内容？ | 筛选来源、查看详情、关注、收为候选 | 独立一级导航；热度不等于事实 |
| 选题发现 | 哪个话题值得写？ | 编辑问题、判断读者价值、开始创作 | 不强迫填写七项简报字段 |
| 作品库 | 我写到哪一步了？ | 搜索、按状态筛选、继续作品 | 一篇作品承载主稿/平台稿/素材 |
| 创作空间 | 如何写好并核查？ | 主稿/公众号/知乎、审阅、配图 | 正文居中；建议不能默认覆盖原文 |
| 视觉工作台 | 哪张图最适合这处正文？ | 候选比较、单图修改、采用、返回正文 | 选中候选与真正采用必须区分 |
| 发布中心 | 哪些渠道已经可以交付？ | 渠道独立审核、预览 | 导出≠草稿≠实际发布 |
| 内容日历 | 什么时候准备内容？ | 周/月视图、查看排期 | 日历不应自动执行未授权发布 |
| 效果复盘 | 哪些创作决定真的有效？ | 阅读真实数据、人工确认学习 | 没数据时不造假统计 |
| 素材库 | 图片和论据来自哪里？ | 筛选、打开、关联素材 | 出处、权利和使用历史可追踪 |
| 偏好与连接 | 怎样定制文字风格和服务？ | 编辑画像、管理模型及授权 | 凭据不暴露在原型里 |

## 视觉规范

- 主侧栏：深色 **#242635**，产品状态和工作区入口统一。
- 主操作：蓝色 **#465FD7**；背景 **#F7F8FA**、白色卡片。
- 纸张正文有独立阅读容器，不与设置混为一页。
- 主操作强调一次判断；次级操作使用简洁描边，异常状态用文字而不是只有颜色。
- 桌面：可浏览侧栏 + 内容区；编辑器两侧保留大纲/Agent（窄屏收敛）。
- 手机：底栏工作台/热点/选题/作品/配图/更多，所有页面垂直阅读，不挤三栏。

## 关键交互验收

1. 从热点列表打开详情；点击「收为选题候选」转到选题。
2. 在选题页确认角度、证据不足，点击「开始写作」进入创作空间。
3. 在创作空间切换主稿/公众号/知乎；右侧切换「事实审核」与「AI 配图」。
4. 按封面 / 全文 / 指定段落规划配图；点击「进入配图工作台」。
5. 选中封面或正文配图，切候选版本。**只选中时正文不变**。
6. 点击「采用这张图」，返回创作空间才出现已采用图片；其他槽位保持原状态。
7. 发布中心的公众号与知乎检查独立，不做任何真实平台操作。
8. 在手机上能使用底部导航；其他页面通过「更多」抽屉访问。
9. 数据统计、文章内容、模型生成与素材上传必须始终标为示意而非真实。

## 下一步正式实现映射（不是本分支已完成事项）

| 现有代码 | 未来功能版界面 |
|---|---|
| components/CreatorShell.jsx、CreatorHome.jsx | 统一 Creator V2 Shell / 工作台 |
| components/CreatorTopics.jsx，lib/creator-api.mjs | 独立热点雷达与选题发现 |
| components/WritingWorkspace.jsx、DoocsEditor.jsx | 创作空间；保留实际 Markdown、不可变修订和自动保存 |
| components/WritingImages.jsx | 编辑器内的配图位置规划和摘要 |
| components/IllustrationStudio.jsx | 视觉工作台：候选、改图、采用、版本 |
| components/IllustrationQueueWorkspace.jsx | 单图执行状态、失败隔离和重试 |
| components/PublishingControls.jsx | 渠道独立核查与交付状态 |
| components/CreatorLibrary.jsx | 带来源链和引用关系的素材库 |
| components/CreatorSettings.jsx | 统一创作者画像与连接页 |

**不能引入第二套正文持久化模型。** 主稿与公众号/知乎稿仍应分别保留版本与 expectedRevision 冲突检测。所有图像计划绑定原稿修订；旧计划失效后需要重新审阅并保留旧素材。图片成功生成不等于已被作者批准，也不等于版权和平台可用性已经通过核查。
