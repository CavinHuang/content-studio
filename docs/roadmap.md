# 下一阶段建议 · V24

优先：

1. 在允许联网的电脑执行 AIHOT Snapshot / Changes、6 源抓取，记录真实 schema、429、长连接失败和 RSS 有效性（不打开自动发布）。
2. 将问题假设落到「验证账本」：来源片段、问题类型、用户原话（取得授权）、复现实验、否定证据与验证状态；建立可以人工驳回 AI 建议的能力。
3. 设计「每日精选 5–8 条」的决策页，优先呈现真实复现及原创角度；已看过、已收藏、已写作可反馈到排序。
4. 允许多个原始 URL 代表同一事件的人工合并与拆分，并记录操作和回滚依据。语义聚类仅作候选建议，不自动覆盖人类判断。
5. 真实用户和微信／知乎编辑器验收后再进入 V1.0 生产实现评审。
