- [x] 稳定段落 ID 与不可变历史；并发旧修订保存返回 409。
- [x] 主稿修订不覆盖渠道稿；需人工确认采用新版主稿，历史仍保留。
- [x] 跨渠道版本、证据、人工核对与导出状态相互隔离。
- [x] 研究未关联时禁止伪造证据锚点；关联知识卡时验证研究关系。
- [x] 原句必须精确匹配段落，证据必须属于知识卡版本。
- [x] 研究重新打开会产生精确更正任务；变化的引用不能被静默发布。
- [x] 四项人工确认前、渠道未复核主稿、更正任务未处理时禁止导出。
- [x] HTML 输出过滤或转义不可信文本，不包含可执行的注入脚本。
- [x] 作者登记发表仅在当前已导出修订允许；新编辑恢复草稿，同时保留旧发表历史。
- [x] 浏览器桌面和手机端可以编辑、保存、切换渠道、查看版本历史和人工核对，没有页面级横向溢出。

## 运行方法

```bash
npm run check
npm test
python test/browser_v27.py
```

`test/browser_v27.py` 使用 Node HTTP API 和真实临时 SQLite 数据库，但页面由 `page.set_content` 注入 Chromium。它**不能**代表真实 URL 导航、浏览器持久化行为、外网部署或生产浏览器安全策略。桌面/移动截图均为实际 HTML 的 Chromium 渲染，使用本地测试文章。

## 剩余风险

- 尚未验证真实公众号/知乎的复杂富文本、图片、代码、表格粘贴效果和平台审核策略。
- 对旧 V21 localStorage、旧 V26 文章引用的迁移仍需要按用户确认逐篇执行，不能后台静默迁移或覆盖。
- 缺少对生产环境的多用户访问控制、数据备份、审计、防 CSRF、资源限制与并发压力测试。
- 现阶段信息源和研究记录仍不能替代事实核验；任何 `reported_published` 都只是作者填报，不是第三方核验。
