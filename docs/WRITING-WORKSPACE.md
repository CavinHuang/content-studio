# 集成写作工作台：首个实施切片

日期：2026-10-16。对应 [产品 V1](PRODUCT-V1.md) 中的单篇文章协同写作能力。

## 已实现

- `/compose` 使用本地集成的 doocs/md Markdown 编辑扩展和渲染模块，支持源码/预览/分栏、文本格式、撤销重做和三个主题。由 React 直接挂载 CodeMirror，没有第二套文章存储或公共编辑器站点。
- 首页与选题入口创建空白 Markdown 主稿；已有 Brief 的来源在素材栏展示，经作者本次授权后进入模型上下文。公共源的采集能力仍沿用现有实现。
- 右侧写作助手区分“讨论”与“修改正文”。讨论保存回复但不修改文章；修改生成持久化建议，在原文位置审阅后接受/拒绝。可选区或全文操作。
- 自动保存、不可变历史、恢复为新版本、双窗口乐观锁、保存中继续输入，以及标签页本地未保存草稿恢复。冲突时停止自动保存，保留本地内容，支持下载后与服务器版本合并。
- 同一工作台的配图面板可规划全文或当前主稿段落，使用现有图片服务和预算，生成、选择图片，按段落位置批量插入。上传和素材库插图也可用，插入不删除原选中文字。
- 主稿、公众号和知乎分别保存。可明确从主稿创建平台稿，再通过 AI 修改适配；不会自动覆盖已有平台编辑。
- 当前版本四项检查完成后可复制排版或导出 Markdown；本地资产先解析为已登记的平台 URL。保留独立导出快照和作者报告发布链接，导出不会标成发布。
- 原 doocs 独立交接页面移至 `/compose/handoff`；历史排版稿仍可读取。迁移存在两种正文时必须先选择起点。

## 实现与接口

| 文件/接口 | 职责 |
| --- | --- |
| `components/WritingWorkspace.jsx` | 当前文档、自动保存、讨论/建议、版本、素材、平台稿及发布准备 |
| `components/DoocsEditor.jsx` | 受控 CodeMirror、doocs 编辑命令、选区和内联建议 |
| `components/WritingImages.jsx` | 现有配图领域服务的文章内入口 |
| `lib/doocs-preview.js` | doocs renderer、本地净化、受控样式和复制输出 |
| `src/writing.mjs` | Markdown 修订、块位置、Brief 上下文、模型协议、建议审阅和导出 |
| `POST /api/writing/projects` | 创建空白主稿，接受现有 briefId |
| `GET/PUT /api/writing/projects/:id/:channel` | 读取/保存正文，保存需 expectedRevision |
| `GET .../history` | 读取不可变版本；恢复使用 PUT 创建新修订 |
| `GET/POST .../suggestions` | 历史、讨论或修改建议；POST 需本次外部调用授权 |
| `POST .../suggestions/:suggestionId` | 接受/拒绝，接受需匹配基础修订和原文 |
| `POST .../export` | 检查后创建 Markdown 交付快照 |

Markdown 附属记录使用现有 reference_id + revision。正文、段落派生索引、检查失效、审计和建议接受在同一事务写入。已进入 Markdown 模式的文章不能通过旧段落或旧排版写接口覆盖；旧历史原样保留。代码、表格、图片等完整源文本不会经过有损的段落拆行回写。

选段配图使用当前主稿块 ID，拒绝过期版本与不属于该文章的锚点。图片插入后正文产生新修订，旧计划按既有规则过期；应先生成并选好本批图片再批量插入。平台稿的选图插在当前光标/选区之后；直接段落规划目前限定主稿。

## 运行与模型

使用 Node >=22.16、npm 10.9.2，执行 `npm ci`、`npm run dev`。生产使用原 build/runtime guard，不绕过构建封存或本地访问边界。

写作沿用服务端 `CONTENT_AI_BASE_URL`、`CONTENT_AI_MODEL`、`CONTENT_AI_API_KEY`。缺配置时界面禁用生成，不返回伪造文章。配图沿用 `CONTENT_IMAGE_*`，有独立授权与请求预算。通过 `.env.local` 或运行环境安全设置密钥，不提交值，不使用 NEXT_PUBLIC 前缀。自定义用户级连接、计费账户和密钥管理尚未实现。

上游源码固定提交、许可、本地修改和哈希见 [vendor/doocs/README.md](../vendor/doocs/README.md)。生产不依赖临时审计目录。此切片复用了编辑与渲染模块，未包含独立 Vue 应用的全部 UI、插件、图床和主题市场。自动远程图表/MathJax/CDN 脚本不执行；源文本仍会完整保存。

预览净化 HTML，外部图片默认不发起请求，本地图片通过资产预览接口读取。用户点击复制时才生成带 HTTPS 图片地址的排版交付内容，实际平台表现仍需检查。标签页草稿存于 sessionStorage，非跨设备同步；若浏览器禁止/清除存储仍需依靠服务端自动保存或下载。

## 阶段边界

这是可运行的本地单篇创作切片，不代表整个 V1 或多用户 SaaS 完成。以下仍需实施：

- 多用户身份与 workspace 隔离、用户级服务连接和额度账本；
- 个性化选题对话、作者画像学习与内容系列后台调度；
- 小红书独立稿、Agent 整组图片制作和单页自然语言编辑；
- 官方平台账号授权、媒体上传与草稿箱适配器；
- 统一资产检索、跨文章复用和效果复盘。

本轮写作及图片的浏览器验收使用合成 loopback 供应商，不证明真实服务商调用或实际发布成功。验证结果见 [WRITING-WORKSPACE-QA.md](WRITING-WORKSPACE-QA.md)。
