# Content Studio 产品方案 V1

状态：用户多轮讨论确认的产品基线。V1 业务实现与实际验证边界见 [开发验收表](CREATOR-V1-QA.md)。
日期：2026-10-16。代码盘点与技术方案见 [PRODUCT-IMPLEMENTATION-PLAN.md](PRODUCT-IMPLEMENTATION-PLAN.md)。

## 定位与完整路径

面向多个独立创作者的 AI 内容工作空间。每位作者独立管理内容、画像、模型服务与平台账号。

选题 → LLM 协同写作 → 配图 → 独立平台稿 → 作者确认后交付与发布 → 资产复用及画像积累。

平台优先级：微信公众号、知乎、小红书。小红书属于 V1 的完整范围，不因优先级而取消。

## 页面与工作台

五个主要入口：首页、选题、创作、资产库、创作者设置。发布从文章进入，首页汇总进度。

| 页面 | 主要操作 | 结果 |
| --- | --- | --- |
| 首页 | 继续文章、处理待确认事项、查看系列下一篇 | 回到具体创作任务 |
| 选题 | 个性化推荐、输入想法、链接、文件、AI 讨论 | 可编辑的创作简报 |
| 系列计划（选题内） | 设定目标、顺序、节奏、暂停计划 | 下一篇选题、大纲、素材准备 |
| 创作 | 编辑、AI 对话、配图、平台适配、发布 | 文章及独立平台版本 |
| 资产库 | 搜索、筛选、查看来源、选取复用 | 带来源的新创作上下文 |
| 创作者设置 | 画像、视觉偏好、服务与账号 | 作者可控的长期配置 |

创作工作台：顶部为标题、保存状态、主稿/公众号/知乎/小红书切换及发布；左侧为可收起的大纲和素材；中间为 doocs/md 编辑与预览；右侧为可关闭的 AI 对话与配图。排版设置默认收起。小红书使用正文与整组图片预览视图。

## 选题与系列

- 公共信源与作者自有订阅、链接和文件结合。平台抓取及文件格式的实际支持范围需独立验证。
- 推荐结合领域、读者、写作目标、历史内容及系列计划，展示推荐原因、来源时间、待核实信息和重复提示。
- 卡片支持讨论、开始创作、收藏和不感兴趣；反馈原因可选。
- 简报包含问题、读者、角度、核心观点、素材、证据缺口和目标平台，可随时调整。
- 系统按作者节奏后台准备下一篇候选选题、大纲和素材，首页站内提醒；同时支持立即准备。
- 作者确认后开始文章，不自动生成完整成稿或执行发布。计划可暂停、调整和结束。

## 协同写作与主稿

- 使用 doocs/md，目标为同一工作台内的编辑、预览、主题和排版体验。
- 不强制先确认大纲：讨论观点、生成大纲、生成初稿、直接输入均可作为起点。
- 初稿可直接写入；修改已有正文先在原位置展示差异，逐项接受、拒绝或继续调整。
- 选中文本支持改写、精简、扩写、调整语气、配图及自定义要求；助手也支持全篇任务。
- 展示本次使用的画像、素材和个人资产，作者可增减上下文；引用资料显示来源。
- 自动保存，保留可恢复版本；AI 处理期间作者可继续写。旧建议不得覆盖后来编辑的内容。
- 主稿衍生独立平台稿。主稿更新提示差异，由作者决定同步内容，禁止静默覆盖。

## 配图与小红书成品

文章配图同时支持全文位置推荐和指定段落生成。生成前展示用途、画面方案、数量、模型及预计消耗，作者确认后执行。候选图选用后插入指定位置；支持上传、替换、参考图修改和局部重做。

小红书由 Agent 完成：文章改编 → 标题/正文/话题 → 分页与视觉方案 → 作者确认 → 整组图片生成 → 检查 → 作者审阅 → 下载或可用的发布操作。

- Agent 负责封面、页数、每页重点、图片及文字排版，输出实际发布图片。
- 作者无需逐页手动套模板；可自然语言修改单页、拆页、调整整组风格。
- 保存每页文案、布局、素材、生成要求和版本，支持只重做选定页面。
- 检查文字、溢出、裁切和风格一致性；检查结果不能替代作者最终审阅。
- 图片制作可包含背景生成、图像编辑与精确文字合成，由 Agent 编排。不得仅输出排版方案并声称已生成图片。

## 发布及版本

优先通过可用官方接口发送草稿箱；同时提供复制排版、文件导出和图文下载。接入能力取决于平台与具体账号权限。

发布前确认账号、标题、正文、封面、图片、平台要求及四项人工检查（事实、隐私、权利、排版）。这些检查按当前平台版本分别记录。

区分编辑中、待确认、已导出、已发送草稿箱、作者确认已发布、平台核实已发布。失败、执行中和结果待确认属于操作状态。导出或草稿箱成功不能升级为已发布。

人工发布可补链接、时间并确认；保留证据来源。每次交付/发布绑定当次内容和图片版本。文章后续编辑不修改历史记录。

同一作者可以连接多个平台账号（实施建议，尚未经专门交互评审）；首次使用只需配置一个。账号可继承画像并覆盖平台定位。

## 资产与画像

创作开始即保存资产，发布补充发布版本、链接和效果。资产包括文章、图片、参考素材和创作经验，支持按主题、系列、平台、时间检索与复用。删除文章不应无提示删除被其他文章使用的资产。

明确偏好直接生效；LLM 从作者选定历史文章、接受/拒绝的修改及最终确认稿提取推断，作为可确认、修正、删除的建议。保留依据和版本，支持暂停学习及单篇覆盖。写作风格、视觉风格、事实和作者观点分别处理。不同平台可以有不同表达偏好。

资产首先归作者私有，跨用户共享必须主动选择。AI 引用资产展示来源。效果数据先人工记录，自动获取按平台能力接入；不自动用阅读量改变写作画像。

## 服务与完成标准

平台统一提供模型，同时支持作者自配 LLM 和配图服务。写作与配图可分别选择，费用与额度可见。每次尝试最多 1 次模型请求的上限约束非 agent 的单次生成路径；agent 运行见 [AGENT-V1.md](AGENT-V1.md)：多步循环、v1 不设请求数上限、逐次记账并受每日额度约束。

V1 完成应有真实可操作的路径：新作者建立空间 → 确认选题 → 编辑器中生成和修改文章 → 生成并选用图片 → 适配三个平台 → 小红书生成可下载成品图 → 完成可用交付操作并准确登记发布状态 → 检索资产用于下一篇。系列准备和画像建议也应能够持久化并由作者控制。

阶段性演示可以先完成公众号单篇路径，但不得称为整个 V1 已完成。真实模型、浏览器、平台草稿箱与真实发布验收分别报告。
