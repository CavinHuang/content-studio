## 测试环境限制

原生浏览器访问 `127.0.0.1` 在此自动化环境受限制；Chrome 浏览器测试通过 `page.set_content` 注入真实 HTML，并将 API 请求代理到**实际运行中的 Node 服务**。因此网页点击 + 后端接口逻辑联通，但无法据此宣称已验证正常浏览器导航、真正域名 CORS、跨刷新保存及生产部署。
