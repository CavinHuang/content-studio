# V22 高保真交互修订说明

## 对 V21 的修改

- 保留 V21 五项业务导航和完整创作体验，左侧额外出现“真实信息源 · V22”入口；桌面、手机都可跳转 `/live`。
- `/live` 使用 V21 同系浅灰底、白卡片、低饱和森林绿、清晰边框的编辑工作台，不做第二套品牌主题。
- 聚合事件列表与证据详情并排，展示原文链接和不同源的角色分类；右侧一键创建独立 Brief 并进入 V21 的 `Brief` 编辑。
- 信息源状态显式显示“未连接 / 成功 / 304 无变化 / 错误”，保留上次成功和 next_retry 信息。
- 首次空状态引导真实同步；离线导入演示样本必须操作确认，样本有顶部黄色提示，标题包含 scenario fixture。
- 两端均不宣称当前新闻已验证、官方宣发已独立证实或外部平台已经发布。

## 关键交互状态

| 场景 | 界面 | 规则 |
|---|---|---|
| 从未同步 | 空事件列表，信源为“未连接” | 不自动插入假新闻 |
| 成功同步 | 展示条目数、来源数、事件源头 | 可继续创建 Brief |
| 304 | 来源显示“304 未变更” | 旧条目留在缓存 |
| 429 | 显示出错、下一次允许重试 | 没有密集并发重试 |
| 不同源同原文 | 一个事件，多条角色化来源 | 社区讨论≠独立证据 |
| 新建 Brief | 来源快照写入 SQLite，`/app?brief=...` | 旧文章保留，不覆盖主稿 |
| 浏览器离线 | 显示请求失败 | 不宣称成功或偷偷转为演示模式 |

## 待加强

- 中文标题搜索可增加同义词与跨语言匹配，但不要冒充 AI 已验证。
- 结构化富文本多端渲染、审核重检、公众号／知乎真实版式仍待后续阶段。
