# UI / UX 连续操作复查

日期：2026-10-26。基于设计系统 v2.3；复查连续切换、窗口缩放、长内容与弹窗焦点。

## 本轮发现与修复

| 可复现的问题 | 修复后的行为 |
| --- | --- |
| 从左侧切换同一篇内容的产物会清空 Agent 输入，上方产物 Tabs 却会保留 | 两个入口统一，切换产物保留当前会话的输入与引用 |
| 添加素材引用会将已写好的指令替换成固定示例文字 | 保留已输入的文字；仅空输入时填入示例提示 |
| 切换会话或进入热点时携带另一会话的未发送输入；新建对话又会丢弃原输入 | 按内容项目和会话隔离输入与引用；发现对话独立保存；切回可继续编辑，发送只清空当前会话 |
| 当前内容移入回收站后，输入与引用仍跟随到下一篇内容 | 输入和引用绑定原内容，不进入新的当前内容；恢复原内容后可在本次运行内继续 |
| 跨过桌面布局断点会重新创建编辑区，已打开的详情关闭，页面局部状态丢失 | 同一个编辑区宿主移动到新的布局容器，保留页面实例、详情、输入焦点和选区 |
| 缩窄窗口时，桌面面板的开关短暂触发手机抽屉，干扰已有弹窗 | 桌面 Agent 面板与手机抽屉分别管理；侧栏抽屉直接使用移动端开关，不复用桌面开关 |
| 长标题占满弹窗，正文区域受到挤压；缩放后正在编辑的输入框被滚出视野 | 标题与正文共用滚动区，底部操作和关闭按钮独立保留；容器尺寸变化后将正在编辑的控件滚回可见范围 |

## 样式边界

继续使用设计稿配色、现有系统字体及 shadcn 默认控件。没有修改 `components/ui/` 下官方原组件的字号、字体、边框、尺寸或内边距。新增排列与滚动约束位于工作台和业务 Modal 包装层。

未发送的 Agent 草稿保留在本次应用运行中；刷新或重新启动后的草稿恢复尚未实现。替换示例数据或导入备份时清空这些临时草稿，避免与恢复后的同名会话混用。

## 验证范围

- 连续经过产物、会话、内容项目、热点和来源管理，验证输入和引用隔离、返回恢复、发送清理。
- 在 1480、1099、767、390 像素宽度间连续切换，验证同一详情实例、无额外抽屉、操作按钮可见、无横向溢出。
- 使用包含长中文和连续英文的素材标题，验证滚动区域、当前输入可见性及关闭入口。
- 验证确认框和详情框依次关闭时的焦点返回，以及正文编辑焦点和选区的保留。
- 所有测试使用隔离临时数据，不操作当前工作区的数据。

本轮实拍与验证记录保存于 `implementation/continuity/`。常规页面与状态实拍见 [设计与实现对照](alignment.html)。
