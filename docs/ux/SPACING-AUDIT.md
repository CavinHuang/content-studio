# 全页间距校准

日期：2026-10-25；规范版本 v2.2。颜色继续使用已确认设计稿，字体、圆角和基础控件尺寸保持 Tailwind / shadcn 规范；业务布局使用 Tailwind 刻度做紧凑组合。

此文保留 v2.2 的间距调整记录。当前通用控件以 v2.3 为准：官方 Field 使用 gap-3，MessageContent 使用 gap-2.5，普通文字操作使用 sm Button，不再用业务 CSS 覆盖内部间距。最新审查见 [UI-UX-AUDIT.md](UI-UX-AUDIT.md)。

| 元素关系 | 当前间距 |
| --- | --- |
| 标题与说明、紧密元信息 | 4px |
| 相关按钮、标签与控件、消息内部 | 8px |
| 列表卡片间距、业务卡片内边距、表单网格 | 12px |
| 工作台页面边距、主要区块、Agent 消息之间 | 16px |
| Dialog 外框 | 保留官方 24px |
| 内容库菜单 / 子菜单 | 保留 32 / 28px 行高，子级缩进约 15px |
| 常规 Button / Input | 保留默认 36px 高度 |

## 已处理的问题

- 导航、页面工具栏与 Agent 外边距对齐；侧栏搜索与导航间距收紧。
- 标题说明位于标题下方，右侧多行操作不再把两者撑开。
- 字段底边距与网格 gap 不再叠加；最后一个字段不再给弹窗底部增加空白。
- 卡片标题按钮移除通用 Button 内边距；热点、素材、来源、服务与任务列表采用 12px 组合。
- 发布平台将名称和说明放在同一内容列，移除复选框额外外边距及手算说明缩进。
- 任务图标与正文并排；表单下拉框填满字段，避免无意义的列内空白。
- 视频分镜卡片不再同时使用外框、标题栏、内容区三层内边距；时长标签不换行，下拉框与图片宽度对齐。
- 视频入口、字幕、候选、版本、导出状态与底部操作区分别校准；预览比例与画布保留。
- Agent 消息从默认 32px 间隔改为显式 16px，内部为 8px；结果卡移除重复 margin，复制选用官方 xs。
- 素材收集、平台选择、版本对照、排版浮层和空态检查其内部间距；官方 Dialog 外框保持不变。

## 验证与边界

117 处业务 CSS 原位调整；组件组合中明确写出 p-3、gap-3、gap-0 等选择，未添加新的样式覆盖文件，未修改官方组件的默认间距刻度。

`pnpm ux:capture` 对桌面、窄桌面和手机共 56 个状态截图，记录真实 padding / gap / margin；断言页面 padding 为 16px、可见 Agent 消息 gap 为 16px、表单网格字段底边距为 0，同时继续验证溢出与裁切。记录位于 [checks.json](implementation/aligned/checks.json)。

11 个主要页面的间距实测见 [spacing-review.json](implementation/aligned/spacing-review.json)，本轮规则清单见 [spacing-adjustments.json](implementation/aligned/spacing-adjustments.json)。下拉箭头、侧栏徽标和管理按钮预留的尾部空间，以及文章末尾的阅读空间，保留其用途。

文章字体、行高、段距和页边距仍由平台排版参数控制；视频画布和插画内部留白不参与工作台 UI 的统一压缩。
