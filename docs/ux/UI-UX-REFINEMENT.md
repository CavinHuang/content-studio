# UI / UX 精细修复

日期：2026-10-25；基于设计系统 v2.3。继续保留确认的配色，使用原有 shadcn 组件及其默认尺寸、字号、圆角和内边距。

2026-10-26 的后续复查与最新验证结果见 [连续操作复查](UI-UX-CONTINUITY.md)。

## 本次修复

| 问题 | 修复后的行为 |
| --- | --- |
| 会话标题与消息数挤在固定高度按钮里 | 改用官方 DropdownMenuRadioGroup / RadioItem，自然容纳两行；当前会话有选中标识，长标题省略并保留完整 title |
| 会话菜单缺少方向键导航和清晰的焦点恢复 | 方向键选择、Enter 确认；选中后进入 Agent 输入框，Escape 返回触发按钮；菜单内新建会话后可直接输入 |
| Agent 浮层跨过分隔线或挤出窄面板 | 使用组件的 collisionBoundary / collisionPadding 和可用宽度变量，将会话菜单与素材选择器约束在 Agent 面板内 |
| 素材选择器长标题挤压操作图标 | 标题独占可收缩文本列，长文本省略，图标保留；列表按可用高度滚动 |
| 素材选择器打开后，关闭按钮自动获得焦点并弹出 Tooltip | 打开后聚焦第一项素材；没有引用素材时聚焦收集入口；关闭或选择后回到输入框 |
| 任务筛选缺少可见和可读的选中状态 | 使用标准 secondary / ghost 按钮变体和 aria-pressed；不再自改按钮高度与内边距 |
| 任务计数、筛选与空态含义不一致 | “进行中”包含排队与运行；“失败与停止”包含两类状态。筛选无结果时提供“查看全部任务” |
| 素材搜索无结果仍显示首次收集文案 | 区分筛选无结果、项目未引用和全局空库；可清除筛选或切换全部素材，从已有素材开始复用 |
| 清空搜索或退出空态后焦点落回页面 | 清除搜索／筛选后回到输入框；查看全部素材后回到对应 Tabs；查看全部任务后回到筛选按钮 |
| 素材网址、文件名与首尾空格影响搜索体验 | 查询去除首尾空白、忽略大小写，并检索标题、正文、标签、网址和文件名 |
| 素材展开按钮只改变图标，没有展开语义 | 补上 aria-expanded / aria-controls；被控内容保留稳定 ID，收起时隐藏 |
| “选题”看起来是标签，点击却不能聚焦 | 使用官方 Field / FieldLabel，点击标签直接聚焦选题输入框 |
| 保存成功也表现为可点击按钮 | 正常保存使用 status 文本；失败时才显示重试按钮。成功、保存中、失败图标分别使用主题中的成功、次要和错误色 |

## 组件与样式边界

本次修改集中在业务组件组合和焦点逻辑，没有调整 shadcn 原组件的高度、字号、内边距或字体栈。移除旧的会话菜单、素材选择器和选题专用 CSS，浮层边界使用 Radix 提供的定位 API；可收缩文本列、隐藏内容、外层排列使用局部 Tailwind 类表达。

测试使用隔离临时数据，不修改用户当前工作区。原有 Mock、正文排版和平台选择方式保留。

## 验证

新增专项覆盖长会话和素材标题、菜单与面板边界、方向键选择、焦点返回、清除搜索、空态恢复、素材展开语义、标签关联，以及本机保存失败后的重试。保存失败通过测试环境的一次性存储异常模拟，生产代码没有故障注入逻辑。

最新页面实拍见 [设计与实现对照](alignment.html)，详细状态与布局检查见 [checks.json](implementation/aligned/checks.json)。专项浮层实拍保存于 `implementation/refined/`。

验证结果：17 项全量交互回归通过，最后的空态恢复与焦点补充专项也通过。56 个页面状态的运行错误和布局问题为零；开发预览、设计边界与格式检查通过。最后的焦点补充只改变焦点去向，不改变页面排版。

专项实拍使用测试环境的长标题数据：[会话菜单](implementation/refined/conversation-menu.png)、[素材选择器](implementation/refined/material-picker.png)。[精细修复检查记录](implementation/refined/checks.json) 保留验证范围。
