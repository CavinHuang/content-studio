# 当前界面与设计参考

日期：2026-10-25；配色遵循已确认设计稿：米白画布、浅沙侧栏、墨绿主操作、浅陶土平台选中态与用户气泡。字体、间距和组件尺寸遵循 Tailwind + shadcn 默认规范。

## 本轮统一

- 接入官方 Tailwind / shadcn CSS 入口，通过统一语义 Token 使用设计稿配色；采用默认 font-sans，不再打包自定义字体。
- 删除原有三层覆盖 CSS；业务结构统一位于 components 层，基础控件 utilities 决定外观。
- 恢复 Button h-9、Input h-9、Card 和 Dialog 默认结构，使用标准 variant / size。
- 常规间距、字体和圆角复用 Tailwind 刻度；807 处业务间距声明迁移为 @apply 工具类，不再维护单独的 density 表。
- 搜索改用 Input Group，表单、菜单、平台 Tabs 和 Agent 均遵循组件默认样式。
- 保留三栏、建议折叠 / 展开 / 定位、采用与撤销、独立平台版本、两条视频路线和发布显式选择。

文章的用户排版设置只影响内容，不参与工作台样式。未改动过的旧默认正文排版升级为 sans / 16px / leading-7；用户明确调整过的参数保留。

v2.1 恢复设计稿配色，主题覆盖所有业务页、对话、浮层和状态标记；内容插画及平台品牌色保留。次要文字稍加深，保证在各浅色背景上达到 4.5:1。此次调整保留现有组件尺寸与响应式布局。

## 复核

[离线对照页](alignment.html) 展示 56 个真实 Electron 状态，包括默认收起与展开建议。运行 pnpm build 后使用 pnpm ux:capture 重拍；使用隔离临时数据，不覆盖用户工作区。

checks.json 记录运行错误、窗口宽度、整页及工作区横向溢出、顶栏操作裁切、Agent 标题重叠、弹窗越界和卡片内部溢出。cohesion.json 是实际字体与栏位测量。此前 density.json 仅为历史间距记录，不再作为当前规范。

设计系统测试补充默认控件 36px、UI 字体一致性与排版滑块实际影响正文。功能回归继续覆盖建议采用 / 撤销、平台独立稿、素材、热点、视频、发布和文件下载。

AI、实时热点、配音、视频编码与自动发布仍是后续接入范围；当前 Mock 标识持续保留。

手机顶栏在栏内横向滚动产物导航，优先保留编辑、发布、更多与 Agent 入口；Agent 抽屉使用 w-full，视频步骤与工具在窄屏换行。新增交互回归确认顶栏操作完整位于视口、Agent 手机抽屉占满可用宽度。

热点分类在手机上独占一行，来源与时间筛选另行排列，排序控件保持可读宽度；产物导航随选中项与可用宽度变化自动滚动到当前选项。手机专项已检查热点、来源、设置、偏好、任务和字幕页的内部实际滚动宽度。

侧栏已采用官方 Sidebar 组件组合：32px 菜单、28px 子菜单、统一浅绿选中态、右侧计数与悬停 / 聚焦操作，顶部收起按钮持续可见。新建按钮、搜索、分组、列表和底部工具分别置于 Header / Group / Content / Footer；移除 66 处旧样式。补充真实交互回归覆盖桌面与手机 Ctrl / Cmd+B、Ctrl / Cmd+K、搜索空态、长标题管理、子菜单导航与侧栏内部无横向溢出。

子菜单缩进复核：官方默认外边距与内边距累计 24px，叠加通用 Button 又增加了 2px。移除通用 Button 包装，并在文件树组合中明确使用 mx-2 / px-1.5，使子级图标相对父级的缩进由约 27px 缩小为约 15px；保持子菜单默认行高与行间距。此处记录为局部紧凑调整，不表述为官方默认缩进。

全页间距校准：117 处业务规则原位调整，覆盖导航、文稿、方案、热点、来源、素材、两条视频路线、发布、设置、任务与浮层。页面边距 16px，列表与卡片 12px，操作 8px，说明 4px；保留正文排版和视频画布。通过真实窗口记录每个状态的 page / card / messages / form 间距，见 checks.json 中 spacing 字段与 SPACING-AUDIT.md。

v2.3 审查清理约 700 行遗留 CSS；通用表单使用官方 Field，普通操作使用标准 Button 变体，文稿视图／素材范围／来源类型使用 Tabs。去掉三栏双边框、搜索叠加 outline、大纲嵌套外框及发布选中卡 inset 阴影。保留配色、外层业务布局、正文排版及视频画布。字段字重与脱离业务容器的同一控件逐项比较；56 状态记录新增 appearance 字段，见 [UI-UX-AUDIT.md](UI-UX-AUDIT.md)。
