# 界面实现

日期：2026-10-25。依据 [UX-SPEC.md](UX-SPEC.md) 实现；2026-10-28 按 P3（热点真实抓取）/ P4（发布链）/ P5（视频导出与配音）更新真实与演示边界。原始设计稿与 `index.html` 总览保持保留。

当前界面已迁移到 shadcn/ui + 官方 AI Elements 组合模式，使用 Tailwind CSS 4 与 Radix。设计 token 与状态规范见 [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)，组件位置、源码来源与维护规则见 [COMPONENTS.md](COMPONENTS.md)。本轮为组件体系迁移，业务数据 schema 保持 v2。

## 体验入口

桌面：`pnpm dev`；浏览器预览：`pnpm dev:web`。首次打开载入三个示例内容项目，刷新后保留修改。未配置真实服务时全部功能保持本地演示，不发起模型请求、平台请求或外网抓取；按下方「真实与演示边界」配置后对应域切换为真实执行。

建议按以下路径体验：

1. **文稿 → 查看修改建议 → 采用 / 撤销**：原稿与建议对照；手动改稿后旧建议会过期。切换公众号、小红书、知乎、X，分别编辑、排版和恢复版本。
2. **热点 → 查看与创作 → 选择来源、修改角度 → 开始创作**：同一原文可保留多个收录来源，来源数与原文数独立；创建内容后先进入可编辑方案。热点发现使用独立对话。
3. **来源管理**：独立启停、按类型筛选、添加 RSS/Atom 订阅或热榜 JSON 来源并真实抓取，演练模拟失败恢复。停用保留已保存的素材与创作快照。
4. **素材 → 收集素材**：支持文字、链接、图片和文件；「本篇引用」「对话引用」「插入文稿」分别操作。删除原素材进入回收站。
5. **视频 → 素材分镜**：镜头排序、换图、调整口播与时长；校对字幕并导出 SRT；本地播放画面示意，保存 / 恢复分镜版本；「导出视频」本机渲染 MP4，配置语音服务后配音真实合成。
6. **视频 → Agent 代码创作**：预览场景，调整明确开放的参数，比较候选与已采用版本；采用之前不改写当前作品。
7. **发布准备**：本批次显式多选平台，预览固定快照；公众号可存草稿箱、小红书可注入草稿，或复制 / 导出人工交付；用户手动发布后再标记结果。未选平台继续保留。
8. **任务中心、设置**：查看成功 / 失败 / 停止状态；演练导出失败和重试；配置模型与语音服务，调整偏好，备份与恢复本机数据，恢复回收站内容。

三栏支持收起、拖动和键盘调整宽度。窄屏使用 Agent 抽屉；手机采用单列与「收集 / 内容 / 任务」底部导航。弹窗支持键盘焦点限制和 Escape，嵌套弹窗只关闭最上层。

## 真实与演示边界

| 项目 | 配置后的真实能力 | 未配置时的演示路径 |
| --- | --- | --- |
| AI | 「设置 → AI 服务」配置 OpenAI 兼容模型后，对话、修改建议、母稿与平台稿生成由真实模型驱动（内嵌 pi agent 运行时） | 本地确定性回复、示例稿与建议；有待确认、采用、过期与撤销状态 |
| 热点 | 用户来源由主进程真实抓取：RSS/Atom 订阅解析、热榜 JSON 适配、正文提取（可读正文 → 页面摘要 → 如实标注仅链接）；抓取进任务系统，支持定时刷新，失败保留缓存不伪装成功 | 内置示例来源提供确定性演示话题（「示例来源 · 演示数据」徽标；可停用不可删除） |
| 视频 | 「导出视频」经本机 Remotion 渲染真实 MP4：帧级进度、可停止、失败可重试，产物保存在本机导出目录并可打开（开发与打包形态均可用：渲染组件与 Chrome Headless Shell 随安装包预置，离线可导出；安装缺损时如实提示未安装） | 制作清单 JSON 与字幕 SRT 下载不依赖配置；代码动画工作台始终为本地组件预览，不执行生成代码 |
| 配音 | 「设置 → AI 服务」配置语音服务后，分镜「更新所选镜头配音」经 OpenAI 兼容 `/audio/speech` 真实合成，音频存本机、镜头时长按音频回填 | 声音与更新状态的界面演示，不播放真实音频 |
| 发布 | 公众号经官方接口存草稿箱（需 AppID/AppSecret 与公众号后台 IP 白名单）；小红书经平台会话注入标题、正文与话题并停在草稿（需扫码登录）；平台间串行限速、失败三分类重试 | 复制（含公众号富文本）与 Markdown/JSON 下载的人工交付；未配置凭证按凭证类失败如实提示 |
| 实际文件 | Markdown、SRT、MP4（真实导出）、制作清单 JSON、发布批次 JSON、项目与全量备份 JSON | 同左（MP4 除外，未导出时只有清单与字幕） |
| 人机边界 | 应用只到草稿：存草稿箱、注入草稿、复制与导出都不会自动发布；正式发布由用户在平台手动完成后回来标记 | 同左 |
| 排版 | 公众号链路使用自有的轻量 Markdown 转公众号 HTML 转换器（转义在前、不产脚本） | 界面排版为安全 React Markdown 预览与独立样式；尚未实际集成 doocs/md |
| 数据 | 应用数据目录内的本机 SQLite（studio.db）；任务由主进程状态机管理，支持停止、重试与重启降级；无云同步 | 浏览器预览降级 localStorage。密钥经 safeStorage 加密保存在本机、只回显尾号、不参与备份导出 |

四张场景配图为本仓库原创 SVG，Lucide 图标本地打包，字体采用 Tailwind / shadcn 默认 font-sans 系统栈。没有运行时外链图片、图标或字体依赖。

## 验证

`pnpm test`（vitest）覆盖主进程模块（存储迁移、任务状态机、AI 编排、热点抓取与聚合、发布编排与适配层、视频导出）与渲染端逻辑；`pnpm test:smoke` 对真实 Electron 窗口验证隔离桥接、编辑保存、平台隔离、版本恢复、热点创建、素材复用与回收、视频候选采用、发布快照、手机布局及真实文件下载，含经 mock OpenAI 端点的 AI 全链路与发布注入边界用例。开发模式也检查 React 热更新与运行时错误。CI 在 Linux 上经 xvfb 以同一组命令运行（`.github/workflows/ci.yml`）。

实际界面截图位于 [implementation](implementation/)，与原始设计效果图分开保存。

组件迁移后的当前截图为 `05-shadcn-workspace.png` 至 `10-shadcn-agent-mobile.png`，涵盖文稿、多源热点、信息源管理、发布平台选择、代码动画与手机 Agent。`01` 至 `04` 保留为迁移前实现记录。

精细校准后的最新截图保存在 `implementation/aligned/`，覆盖 56 个状态及三种窗口尺寸；[打开设计与实现对照](alignment.html)，详见 [校准记录](VISUAL-ALIGNMENT.md) 与 [页面覆盖表](PAGE-COVERAGE.md)。使用 `pnpm ux:capture` 重新拍摄并生成对照页（先执行 `pnpm build`）。设置和任务中心没有独立效果图，依据交互规范沿用通用视觉系统。

当前视觉基础以 [设计系统 v2.2](DESIGN-SYSTEM.md) 为准：配色遵循确认设计稿，采用米白、浅沙、墨绿和陶土色；字体栈、字号、间距与控件尺寸沿用 Tailwind + shadcn 默认规范。
