创作者工作台 · 设计总览

从一个念头，到值得发布的作品。

左侧管理内容，中间制作当前产物，右侧与 Agent 协作。从热点或自己的想法开始，以温暖、轻量的工作环境承接文稿、素材和两种独立的视频创作方式。

20 张效果图多信息源热点创作两条视频路线五个平台按需发布桌面创作 · 手机辅助

完整创作流程

从热点开始：浏览话题与来源 → 选择或改写角度 → 新建内容并确认创作方案。

热点 / 新建内容→素材与创作方案→母稿与修改→平台版本 / 视频作品→选择本次平台→准备内容与手动发布

素材分镜

脚本与素材 → 镜头编排 → 配音字幕 → 预览 → 视频或素材包

Agent 代码创作

创作说明 → 视觉方案 → 候选预览 → 对话迭代与采用 → 视频输出

评审说明：热点分类现有三张界面：多源发现、选角度发起创作、信息源管理。信息源覆盖平台热榜、新闻资讯、RSS 与自定义来源，分别管理启用与连接状态。

早期图中的顶层“分镜”现统一归入“视频”；最新两种制作界面与交互规范是结构依据。图中计数、日期、时长和字数仅作设计示例。
