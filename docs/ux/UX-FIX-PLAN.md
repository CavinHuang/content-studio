## 1. 批次 B1：规范落纸（S1/S2/S3/S4/S5/S6 的"法源"）

DESIGN-SYSTEM.md v2.2 → v2.3，增补四节，并同步 `design-system.html` 与 `design-tokens.json`：

### N1 演示态词表（对应 S1）
- **模式标识 =「Mock」**：仅用于全局状态位（侧栏底栏「本机工作区 · Mock 演示」、右上角统一 badge「Mock · <模块名>」，间隔号两侧留空）。
- **数据内容 =「示例」**：示例话题/示例日期/示例缓存。
- **行为说明 =「演示」**：演示模式、演示存储、本机演示。
- **失败前缀统一「模拟失败：」**，同一原因跨屏同一字符串（修复「示例失败：配乐资源暂不可用」vs「模拟失败：配乐资源不可用」）。
- 同一服务名全局同一字符串：`自然叙述（Mock）` 在设置页与视频页必须逐字一致。
- **`(Mock)` 后缀退出按钮文案**（13「更新所选镜头配音（Mock）」、19「按说明新建预览（Mock）」→ 演示属性由说明区/徽标承担）。
- **非实时示例数据禁止呈现相对时间**（「2 小时内」→ 示例日期）。

### N2 弹窗 footer 规范（对应 S2）
四类模板，落点 `components/ui/dialog.tsx`（`DialogFooter`/`DialogClose` 原语已存在，纯用法收敛）+ 新增一份 `DialogTemplates` 用法注释或 story 段落：

| 类型 | footer | 适用 |
| --- | --- | --- |
| 只读 | 左「复制内容」(若有可复制物) + 右「关闭」 | 22 动画代码 |
| 表单 | 左 muted 说明/摘要 + 右「取消」+ 主按钮 | 32/40/46/49 |
| 轻量即时生效 | 单主按钮 + 右上 X（文案注明即时生效） | 05/35/36/37（若定义为自动保存） |
| 详情（自动保存） | muted「更改自动保存」+ 右侧动作组，破坏动作分离到左下 | 38 |

主按钮图标规则：**＋=创建、→=继续/前进、保存/记录类一律无图标、✓ 仅完成态标识**（✓ 保存素材 → 保存素材；↻/✦ 退役）。

### N3 选中态 token（对应 S3/S4/G10/B6/C4）
- 新增语义 token（`scripts/design-tokens.mjs`）：`--selected-platform: #f3e4d7`（视图切换类平台选中，规范原义）、`--selected-row: 浅绿系`（多选/勾选行）。
- **横排单选唯一语言 = 分段白块式**（TabsList：沙色轨道+白色凸起片）；实底药丸退役（06 顶部筛选、05 弹窗类型、34「全部素材」、10 预览平台 chip 全部改造）。
- 平台选中分两类入规范：**页签/chip 切换 = 浅陶土**；**勾选行 = 浅绿底+墨绿描边**（09/31 现状合法化写入规范）。
- 对勾只表示完成/已选中状态，不作为唯一选中指示（切入点行 B6 补浅绿底）。

### N4 文案规则（对应 S5/S6 + A10/D24/E7/E8）
- 中文问句一律全角「？」；标题不加终止标点，口语句号句仅保留给各模块主页面大标题。
- 量词表：视频作品=「个」、计数徽标=裸数字、版本数=「N 个版本」且必须带「平台版本/修订版本」前缀口径。
- 日期：元信息 `MM/DD HH:mm`，快照/审计 `YYYY/MM/DD HH:mm:ss`。
- 成对操作同一量词（全部/全量 → 统一「全部」）。

**门禁扩展（防复发，落点 `scripts/check-design.mjs`，可新增 `scripts/check-copy.mjs` 并入 `pnpm design:check`）**：
1. 正则禁 `[\u4e00-\u9fff][?!.,;:]`（中文后半角标点）——当前 `studio/types.ts` 27 处、`studio/mock.ts` 7 处即由此抓出；
2. 演示态词表白名单扫描：按钮文案禁含 `(Mock)`；「模拟失败/示例失败/演示失败」仅允许「模拟失败」；
3. 用户可见字符串禁含 `docs/`、`src/` 等仓库路径（E2）。
