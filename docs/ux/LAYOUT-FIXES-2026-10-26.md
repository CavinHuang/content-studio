# Content Studio：布局与核心创作交互修复

日期：2026-10-26。对应 [布局审查 L01–L10](LAYOUT-REVIEW-2026-10-26.md)。本轮已修改实际 React/Electron 界面，集中处理「原始想法与记录 → 可编辑母稿 → 导出」及其必要辅助操作。

后续跨入口复查发现 5 项遗漏，包括旧方案重新生成、视频工具上下文及关闭弹窗后的阻断反馈。见 [连续操作复查](LAYOUT-FOLLOWUP-2026-10-26.md)；下文的通过结果限于已定义测试范围。

证据边界：下面的尺寸、只读状态、下载内容和恢复行为来自代码与隔离工作区中的 Electron 自动化；对操作负担的解释属于设计判断。生成使用本地 Mock，素材为合成夹具，没有目标用户访谈、生产日志、真实创作质量评审或盲评结果。

## 根因与修复对照

问题并非单纯按钮太多：任务状态没有决定界面结构，同一意图分散在原始输入、方案、正文和会话中；辅助内容常驻占位，用户还要自己识别修改范围与当前目标。修复以删除重复入口、共享上下文和保留正文为主。

## 一条任务的前后流程

原路径：新建 → 素材页 → 收集并引用 → 方案页 → 再写主题与观点 → 生成 → 切换编辑 → 校订 → 更多菜单导出。

当前路径：新建 → 一次提供想法和原始记录 → 整理成初稿 → 在正文校订 → 工具栏导出。系统自动带入已有本篇材料，保留原始输入和快照。已有正文时，改变方向只生成候选；重要替换由作者比较后采用。

| 可直接测量的项目 | 冻结的修复前流程 | 当前核心路径 |
| --- | --- | --- |
| 脚本 click 操作 | 9 | 3 |
| 脚本 fill 操作 | 4 | 2 |
| 工作区切换 | 3 | 0 |
| 重复说明原始意图 | 1 | 0 |
| 模拟生成等待 | 1 | 1 |
| 原始记录是否进入生成正文 | 否 | 是 |
| 导出是否逐字等于校订稿 | 是 | 是 |

来源：[冻结基线](research/creation/baseline-before.json)、[当前路径](research/layout-fixed-2026-10-26/prototype.json) 及对应测试。显式动作从 13 次降到 5 次；这只是同一合成任务的脚本计数。`fill` 不是一次键击；自动化耗时不是人类完成时间。真实决策数、阅读确认成本、实际键击、完成率和主观负担尚未测量。

一个明确的代价：完整复走旧「素材→方案」路径时，两个工具的菜单入口使点击从原 9 次变为当前 10 次，[兼容路径记录](research/layout-fixed-2026-10-26/legacy-route.json)。它保留高级控制，但不能宣称所有路径都减少点击。新增的工具入口用于换取正文持续可见；工具内再次切换不必回到全局菜单。是否值得，仍需高频使用方案/素材的作者验证。

## 人机职责、打断与恢复

| 情况 | 系统承担的工作 | 作者动作与最小返工 |
| --- | --- | --- |
| 信息够用、母稿为空 | 快照原始输入、关联素材、偏好，连续完成一次可逆整理 | 一次发起，之后校订；可撤销未被再次手改的首次结果 |
| 缺少主题 | 原地指出缺少什么，保留全部记录 | 只补主题后继续；不追加完整需求问卷 |
| 链接/图片/文件未读取 | 标记未读取，保留来源，不能编造其内容 | 需要使用其中事实时补原文；这是现有 Mock 的能力缺口 |
| 整理失败或停止 | 保留输入、正文与快照；旧 runId 失效 | 一次继续及一次重新等待；不要求重贴材料 |
| 已有正文、改变方向 | 保留正文，生成候选并打开比较 | 调整要求，比较后主动采用或放弃；不自动替换作者立场 |
| 生成期间手改或比较后再编辑 | 检查正文、标题和上下文版本，阻止过期覆盖 | 保留手改；如仍需候选，重新整理与比较一次 |
| 刷新/关闭后恢复 | 从本地数据恢复记录并停止未完成任务 | 主动继续；不静默重复运行 |
| 换窗口尺寸/打开素材详情 | 持久化工作区挂载，保留工具局部状态；真正对话框出现时辅助抽屉让位，关闭后恢复焦点 | 不重填表单，不重新找素材；Esc 和键盘焦点可恢复 |
| 导出/发布 | 导出当前明确范围；发布使用显式目标和固定交付快照 | 作者决定下载、外部发布与记录状态；不把复制或导出算作已发布 |

辅助区、方向弹窗、比较和素材目标选择是本轮新增或调整的交互：分别替代切页、常驻长表单、重复全文核对和猜测目标。它们不构成必经向导，核心任务不用先逐一检查。

## 尚未获得的证明与下一步验收

没有招募、联系或观察真实用户，也没有隐藏版本来源的产物评审。因此当前可以证明已覆盖场景的操作、数据与恢复约束成立，不能证明真实任务更快、负担更低或文章质量提升。

建议后续先招募 5–8 位目标作者，用各自未整理的记录执行同一任务，交叉平衡新旧顺序，保留修改与中断日志。事先约定：能够独立得到可编辑且可导出的稿件；数字、来源、作者立场不被擅改；重要替换可恢复。记录完成率、人类完成时间、主动决策、返工字数/步骤及每任务 1–7 分主观费力度，不能用脚本等待时间替代。

另请至少两名不知道版本来源的评审，按事实与来源忠实度、观点一致性、结构和可编辑性评稿；版本去标识并随机排序。任何数据丢失、不可恢复覆盖或未授权外部操作均为失败；操作减少只有在质量未下降且恢复未变困难时才可计为改进。上述为待执行方案，样本规模不足以作总体统计推断。
