# UI / UX 审查与组件默认样式清理

日期：2026-10-25。对应设计系统 v2.3；配色继续遵循确认设计稿。

后续的交互与细节修复见 [UI-UX-REFINEMENT.md](UI-UX-REFINEMENT.md)。

## 找到的问题与本轮处理

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 表单文字偏粗，与正文和导航不协调 | 整个字段包在 font-medium 的 Label 中，输入内容也继承字重 | 接入官方 Field，独立 FieldLabel 和输入控件，输入文字恢复正常字重 |
| 字段说明与标签的层级混乱 | 多层 `.field` 规则分别设置 12px、14px、行高、颜色和间距 | 删除控件覆盖；保留官方字段、标签及说明的默认排版 |
| 三栏边线显得粗重 | Sidebar / Agent 自身边框和 ResizableHandle 叠加 | 桌面分隔只保留 Handle；紧凑双栏保留必要的一层边框 |
| 搜索聚焦时边框加重 | InputGroup 的 ring 之外，又添加 focus-within outline | 删除额外外框，保留官方焦点样式 |
| 大纲像一组嵌套盒子 | 行容器边框包着已经有边框的 Input | 去掉行容器边框，保留默认 Input 和图标按钮 |
| 普通文字操作尺寸不一致 | 同时使用 h-auto、px-0、py-1 及自定义 gap | 40 处操作使用官方 sm Button，字号、行高和内边距由组件负责 |
| 页签和筛选状态表达不一致 | 素材范围、来源类型及编辑视图用自绘按钮模拟；热点分类选中样式不足 | 改用 Tabs 或标准按钮变体，补上选中语义和键盘行为 |
| 素材图标被压成扁条 | 缩略图 Button 的 h-auto 与多层固定高度 CSS 冲突 | 改用标准 icon Button，图片填充按钮，类型留在文字信息中 |
| 来源和字幕表格出现嵌套圆角边框 | 已有列表外框，又在每行嵌入默认带边框的 Card；业务 CSS 无法稳定改成表格行 | 每行改为普通业务布局容器，只保留外框和行分隔，不修改 Card 原组件 |
| 手机素材类型按钮的图文拥挤 | 旧 CSS 强制按钮内纵向排列，默认高度容不下两行 | 删除内部方向覆盖；手机外层两列、桌面四列，按钮保留默认高度和横向排版 |
| 侧面功能区的字号和留白仍被旧 CSS 修改 | 旧的 Message、InputGroup、按钮、标签页及响应式覆盖持续存在 | 删除重复覆盖，MessageContent / 附件区 / 发送按钮恢复组件默认结构 |
| 服务卡、设置分区和视频分区标题过强 | 同级标题混用 xl、2xl、3xl | UI 分区采用 text-base / font-medium；页面与文档标题保留各自层级 |

## 保留与边界

- 默认系统字体栈、控件字号、圆角、输入高度、边框宽度和焦点光环继续由 shadcn / Tailwind 提供。本轮没有更改 Button、Input、Textarea、NativeSelect、Card 等原组件的尺寸或字体源码。
- `field.tsx` 从官方 new-york-v4 registry 接入，只调整 import 和代码格式。表单组合负责关联标签、输入与说明；没有以标签容器给输入区设置字重。
- line Tabs 保留前一轮的鼠标／键盘焦点修复；默认分段 Tabs 仍使用官方焦点样式。
- 业务 CSS 仍包含三栏布局、页面滚动、响应式排列、紧凑列表卡片、文章排版和视频画布。保留的 `p-3 / gap-3` 是列表卡片的业务组合，不表述为 Card 官方默认值。
- 文稿标题、正文编辑区及视频作品标题是内容编辑界面，继续支持内容字号和排版设置；其大字号不用于普通表单。
- 不新增字体包，也不统一改写 `--font-sans`。Windows 上中英文使用不同系统回退字体属于当前系统字体栈的正常结果。

workspace.css 已从约 5,500 行缩减到约 4,800 行。本轮删除约 700 行重复或冲突样式，并将控件外观与业务布局分开约束。后续业务布局仍可拆分，但不应通过重新覆盖控件字号和内边距实现局部密度调整。

## 验证方式

- 字段控件与脱离业务容器后的同一官方控件比较字号、字重、行高、边框、圆角及内边距，防止祖先样式污染；标签点击能聚焦，说明能被辅助技术读取。
- 检查桌面两处栏边框为 0，由 Handle 独立分隔；搜索框无额外 outline。
- 验证编辑视图、素材范围和来源类型的 Tabs 及热点分类选中状态；继续检查键盘、输入法、弹窗和手机导航。
- `design:check` 增加边界检查，阻止 `.field input / textarea / select` 覆盖、搜索额外焦点框、用按钮模拟文稿视图，以及用 Label 包住整个 Field。
- 实拍及运行记录见 [设计与实现对照](alignment.html) 和 [checks.json](implementation/aligned/checks.json)。记录新增 `appearance`：系统字体栈、字段字重、栏边框；继续保留各页间距和溢出检查。
