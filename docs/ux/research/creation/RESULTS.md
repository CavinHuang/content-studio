# 创作流程重构：验证记录

结论范围：已经实现并验证一条可操作的本地原型路径；尚不能判定真实创作总体负担或成稿质量得到改善。

## 可追溯的程序证据

首次基线取自重构前构建，冻结于 `baseline-before.json`、`baseline-before.md`、`baseline-before.png`。`baseline.json` 是保留的原路径重跑结果；`prototype.json` 为新流程记录。二者均使用合成素材与 Electron 实际窗口。各 JSON 包含逐步操作、生成原文是否含素材、导出检查及明确为空的人类研究指标。

| 指标 | 原路径 | 新路径 | 解释 |
| --- | ---: | ---: | --- |
| 脚本点击 | 9 | 3 | 包含新建和最终导出 |
| 输入操作 | 4 | 2 | 均包含一次作者校订；fill 不是键击 |
| 本夹具需手填的非空字段 | 3 | 1 | 原路径为素材正文、选题、核心观点；预填大纲不计为手填 |
| 点击与输入操作合计 | 13 | 5 | 减少 61.5%，超过预先设置的 30% 程序门槛 |
| 工作区跨页 | 3 | 0 | 原路径：素材、方案、生成后正文 |
| 重复填写同一意图 | 1 | 0 | 原路径需分别填主题与观点 |
| 固定 Mock 等待 | 1 次 | 1 次 | 每次 1 秒模拟，真实模型耗时未知 |
| 原始笔记进入初稿 | 否 | 是 | 只能证明该夹具保留，不能推导内容更好 |
| Markdown 对应校订正文 | 是 | 是 | Electron 下载后读取文件验证 |

自动化耗时仅保存在原始记录中，不作为产品效率提升百分比。脚本没有测量阅读、思考、查找、实际打字或完整成稿所需时间；也没有将点击数量等同于决策数量。

本夹具在选题与观点中填入同一句意图，因此记录一次重复填写；真实创作中两者可能承担不同判断，不能据此认定观点决策普遍冗余。新路径允许尚未形成观点时先保留材料，也会复用作者已经填写的观点，而非替作者确定立场。原路径有一次强制方案确认，新路径的空白稿整理没有独立的方案确认；实际阅读核对时间均未测量。

## 已检查的行为

- 首次整理、直接编辑、真实文件导出，且不创建发布批次。
- 只有链接且无已知主题时原地补问；链接与输入不会丢失。未核验来源不冒充已读取原文。
- 更改方向保留旧稿；候选先对照再采用；手改后的旧候选禁止替换；采用后可撤销回含手改的前稿。
- 停止、运行期间改输入、重启后继续；旧 runId 回调失效。不同项目和回收站项目隔离。
- 整理器异常通过依赖注入模拟，检查输入/原稿保留以及重试真正重放整理；这不是一次真实模型故障。
- 390px 窄屏无页面横向溢出；键盘可从原始输入进入主操作，整理后可访问导出。完整无障碍审计未开展。
- 全局未引用素材不进入本篇快照；原始材料变化不会改变运行中的快照；未存快照的手改在采用时写入历史。

检查类型与命令详见 `../../CREATION-FLOW.md`。最终构建与回归批次见本文件末尾。

## 需要外部证据的结论

以下均为待验证假设，未赋值或给出通过结论：

- 目标创作者能否不经提示理解第一行约定，并独立完成任务。
- 减少流程操作后，内容核对、补写与返工是否增加；总体耗时和 NASA-TLX 是否下降。
- 新底稿的素材忠实度、作者立场、完整度和剩余编辑量是否至少不差于原路径。
- 切换项目或长时间中断后，用户能否理解快照与候选的关系。
- 真实模型接入后的准确性、延迟、成本和错误恢复表现。

新底稿更明确地保留了原始材料，却仍是带占位问题的编辑底稿。不能用缩短到达底稿的路径，替代到达“可发布成稿”的结果验证。匿名 A/B 资料已生成，`blind-review.csv` 与 `user-observations.csv` 仅有表头，未伪造评分。尚无参与者及已授权联系渠道；邀请说明已向用户提出，未发送外部消息。
