间距与组件

  • 页面 p-4；卡片 p-3 gap-3；字段组 gap-3，标签与控件 gap-2。
  • Button default h-9，sm h-8，lg h-10。
  • Input 与 NativeSelect 使用官方 h-9。
  • 侧栏使用官方 Sidebar；菜单 h-8，子菜单 h-7，计数与管理操作由组件定位。
  • 基础圆角 0.625rem，其余按官方半径比例派生。
  • Dialog p-6 / gap-4；焦点与阴影保留组件默认行为。
  • 左 / 右侧栏 16rem / 24rem；顶栏 h-14。

演示态词表 · 文案规则

  • Mock = 模式标识，仅限全局底栏与右上角徽标「Mock · 模块名」；示例 = 数据内容；演示 = 行为说明。
  • 失败提示统一「模拟失败：」前缀，同一原因全站同一字符串；按钮文案不带 (Mock) 后缀。
  • 非实时示例数据禁止相对时间（「2 小时内」→ 给出示例日期）。
  • 中文问句全角「？」；标题不加终止标点；计数徽标裸数字；版本数带「平台版本 / 修订版本」口径。
  • 日期：元信息 MM/DD HH:mm，快照 YYYY/MM/DD HH:mm:ss；成对量词统一「全部」。

弹窗 footer · 选中态

  • 弹窗 footer 四型：只读 = 复制 + 关闭；表单 = muted 说明 + 取消 + 主按钮；轻量即时 = 单主按钮 + 右上 X（注明即时生效）；详情（自动保存）=「更改自动保存」+ 动作组，破坏动作居左下。
  • 主按钮图标：＋ 创建、→ 继续/前进，保存/记录无图标，✓ 仅完成态。
  • 视图切换选中 = 浅陶土 --selected-platform #f3e4d7；勾选行选中 = 浅绿 --selected-row #eaf1e2 + 墨绿描边。
  • 横排单选唯一语言 = 分段白块式（沙色轨道 + 白色凸起片），实底药丸退役；对勾仅表示完成。
样式边界

foundation.css 导入 Tailwind 与 shadcn CSS。workspace.css 只位于 components 层，组件 utilities 拥有更高优先级。移除原来的三层覆盖文件和 unstyled / unset 变体。

文章排版参数只作用于内容；Agent 使用官方 Message / Bubble / Input Group 组合，默认尺寸跟随组件。
