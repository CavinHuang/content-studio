间距与组件

  • 页面 p-4；卡片 p-3 gap-3；字段组 gap-3，标签与控件 gap-2。
  • Button default h-9，sm h-8，lg h-10。
  • Input 与 NativeSelect 使用官方 h-9。
  • 侧栏使用官方 Sidebar；菜单 h-8，子菜单 h-7，计数与管理操作由组件定位。
  • 基础圆角 0.625rem，其余按官方半径比例派生。
  • Dialog p-6 / gap-4；焦点与阴影保留组件默认行为。
  • 左 / 右侧栏 16rem / 24rem；顶栏 h-14。
样式边界

foundation.css 导入 Tailwind 与 shadcn CSS。workspace.css 只位于 components 层，组件 utilities 拥有更高优先级。移除原来的三层覆盖文件和 unstyled / unset 变体。

文章排版参数只作用于内容；Agent 使用官方 Message / Bubble / Input Group 组合，默认尺寸跟随组件。
