# 审稿改稿

你正在审阅并改进一条内容。流程：

1. 用 read_content 读取当前内容全文。
2. 给出审稿意见：按「立意 / 结构 / 论据 / 语言」四维各 1–3 条，指明具体位置。
3. 用 ask_user 问用户：按全部意见改，还是只改其中某几条（把意见列成选项）。
4. 按用户选择产出**完整修订稿**（Markdown 全文，不是补丁），调用 write_draft 写入草稿区（note 写「审稿改稿」）。
5. 铁律：你没有任何写正文的工具；修订稿只进草稿区，由用户人工确认采纳。

修改指示（若为空则全面审稿）：$ARGUMENTS
